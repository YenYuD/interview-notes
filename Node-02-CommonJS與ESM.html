常見的坑

混用會出事

⚠️

用 require() 載 ESM 模組 → 舊版 Node 直接報錯；新版(22+)有限度支援但仍受限。

⚠️

用 import 載 CommonJS → default export 行為很怪，常要寫 import pkg from 'lib' 才拿到 module.exports。

💡

TypeScript 的 "module": "NodeNext" vs "commonjs" 取捨會影響輸出格式。

面試這樣答

30 秒版本

「CommonJS 是 require、同步、執行時載入，難 tree-shaking；ESM 是 import、靜態分析、可 tree-shaking、支援 top-level await，但要寫完整副檔名、__dirname 要用 import.meta.url 算。混用最常見的坑是 CJS 與 ESM 的 default export 互通行為。新專案我會直接用 ESM。」
