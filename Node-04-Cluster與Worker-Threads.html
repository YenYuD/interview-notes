把多核 CPU用滿

Node 預設只用一條執行緒，但機器有 8 核太浪費。Cluster 開多個獨立行程處理大量請求；Worker Threads 開多執行緒跑單一耗 CPU 的運算。

行程 vs 執行緒

🏪

Cluster（多行程）：開多個 Node 行程，各有自己的 Event Loop，共用同一個 port（master 分配連線）。像「開多個收銀台」分攤人潮。適合 I/O bound（API server）。

🧵

Worker Threads（多執行緒）：同一行程內開多條執行緒，可共享記憶體（SharedArrayBuffer）。像「請人專門去後場處理大訂單」，不擋前台。適合 CPU bound（影像、加解密）。

怎麼選

對照表

任務類型用什麼
I/O bound（API、DB）Cluster + 前面擺 load balancer
CPU bound（資料運算）Worker Threads
多數實務用 PM2 / Docker 開多 instance + nginx，不自己手寫 cluster
為什麼不用 Cluster 處理 CPU 任務？

每個行程都有完整 V8 與記憶體開銷，太貴；Worker Threads 共享記憶體較輕。

Worker Threads 怎麼傳資料？

postMessage（序列化複製）或 SharedArrayBuffer（真正共享）。

面試這樣答

30 秒版本

「要吃滿多核：I/O 密集用 Cluster 開多行程共用 port，CPU 密集用 Worker Threads 把重運算丟到另一條執行緒、別卡住主 Event Loop。但實務上我多半直接用 Docker / PM2 開多 instance + nginx 負載均衡，比自己寫 cluster 邏輯簡單可靠。」
