DNS 把人類好記的網域名（example.com）翻譯成電腦用的 IP 位址。為了快，沿路每一層都有快取。

完整查詢路徑

沿路都有快取

  1. 瀏覽器快取 → 沒有就往下
  2. 作業系統 hosts 檔 → 沒有就往下
  3. OS DNS resolver 快取 → 沒有就送到網路
  4. 本地 DNS server（ISP，或 8.8.8.8 / 1.1.1.1）做遞迴查詢：Root →「.com 問誰」、TLD →「example.com 問誰」、Authoritative → 拿到真正 IP
  5. IP 一路回傳，每層順手依 TTL 快取
紀錄類型 & CDN

常見 record

類型用途
A / AAAA網域 → IPv4 / IPv6
CNAME別名（指向另一個網域名）
MX郵件伺服器
TXT驗證用（SPF、DKIM）
NS指定權威 name server
🌍

CDN 怎麼運作：網域用 CNAME 指到 CDN 業者 → CDN 用 GeoDNS / Anycast 回給你地理上最近的 edge 節點 IP → edge cache miss 才回源站。這就是 CDN 能加速的原因。

面試這樣答

30 秒版本

「DNS 把網域翻成 IP，沿路瀏覽器、OS、resolver 都有快取。真要查時本地 DNS 做遞迴：Root → TLD → 權威 NS，拿到 IP 後各層依 TTL 快取。CDN 則是用 CNAME 指過去，再用 GeoDNS/Anycast 回最近的 edge IP，cache miss 才回源站。」

🔗

這題常和 TLS 串成「從輸入網址到看到網頁的完整故事」一起問，是必練的第一題。
