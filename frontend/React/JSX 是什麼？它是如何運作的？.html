REACT 基礎

JSX 不是魔法，它是語法糖衣，背後全是函式呼叫

JSX 讓你在 JavaScript 裡寫類 HTML 標記，但瀏覽器看不懂它。Babel 在編譯時把每一段 JSX 轉成 React.createElement() 呼叫，最終得到描述畫面的純 JavaScript 物件。

核心機制

JSX → createElement → React Element

每一行 JSX 都對應一次函式呼叫。下面這兩段程式碼完全等價：

// 你寫的 JSX
const el = <h1 className="title">你好</h1>;

// Babel 編譯後
const el = React.createElement('h1', { className: 'title' }, '你好');
ℹ️

React 17+ 起，Babel 會改用新版 JSX Transform（import { jsx } from 'react/jsx-runtime'），不再需要手動 import React，但原理相同。

三大特性

面試最常考的 JSX 細節

嵌入運算式用 {} 插入任意 JS 運算式；不能用陳述式（if、for）
XSS 防護React DOM 預設跳脫（escape）所有插值，防止注入攻擊
JSX 是運算式編譯後是函式呼叫，可放在 if/for 裡、賦值給變數
const name = 'Yenyu';
// 嵌入運算式
const el = <p>Hi, {name}！今天是 {new Date().toLocaleDateString()}。</p>;
延伸追問

面試官可能再追

為什麼不能在 JSX 插值裡寫 if 陳述式？

因為 {} 期待的是「運算式（expression）」而非「陳述式（statement）」。若需條件渲染，改用三元運算式 condition ? A : B 或 && 短路。

JSX 屬性名為何用 camelCase（如 className、onClick）？

因為 JSX 最終是 JavaScript，而 JS 保留字和命名慣例限制了某些屬性，例如 class 是保留字所以改為 className。

不用 JSX 能寫 React 嗎？

可以，直接呼叫 React.createElement 就行，只是可讀性差很多。JSX 完全是可選的語法糖。

面試這樣答

30 秒版本

「JSX 是 JavaScript 的語法擴充，允許在 JS 裡寫類 HTML 的標記。它本身不是有效的 JS，需要透過 Babel 編譯成 React.createElement() 呼叫，回傳描述畫面的純 JS 物件（React Element）。JSX 支援用 {} 嵌入運算式，且 React 會自動跳脫插值，預防 XSS 攻擊。」
