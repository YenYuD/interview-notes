REACT 入門

React：宣告式、組件化的 UI 函式庫，而不是框架

React 是 Meta 開發的開源 JavaScript 函式庫，專注於 View 層。你描述資料與 UI 的對應關係，React 負責高效更新畫面；配合 React Native 還能跨平台開發行動 App。

四大核心

為什麼選 React？

宣告式（Declarative） 描述「UI 應該長什麼樣」，React 幫你搞定 DOM 更新
組件化（Component-based） UI 拆成獨立可複用的組件，每個組件管理自身 state
虛擬 DOM 最小化真實 DOM 操作，批量高效更新
Learn Once, Write Anywhere React 技能可延伸到 React Native 開發行動 App
函式庫 vs 框架

React 只管 View，其餘你決定

面向React（函式庫）Angular（框架）
路由自選（react-router、TanStack Router）內建
狀態管理自選（Redux、Zustand、Jotai）內建 Service
HTTP自選（fetch、axios）內建 HttpClient
彈性高，生態多元低，有完整規範
ℹ️

「React 不是框架」是面試常考的概念區辨。它的生態系龐大，但核心只負責 UI 渲染層，架構選擇完全由開發者決定。

延伸追問

面試官可能再追

React 跟 Vue 有什麼差別？

主要差別在模板語法（Vue 用 template，React 用 JSX）、學習曲線（Vue 稍緩）、社群生態（React 更大）。兩者都是組件化、虛擬 DOM。選擇取決於團隊和專案需求。

為什麼 React 叫函式庫而不是框架？

框架（framework）定義了應用程式的整體架構，並控制程式流程（IoC）；函式庫（library）只提供工具，開發者呼叫它。React 只管 UI 層，路由、狀態管理、HTTP 等都不在其範疇，因此是函式庫。
