REACT 概念

Node、Element、Component：三個名詞傻傻分不清楚？

這三個術語層層包含：Component 是工廠，呼叫後吐出 Element（描述畫面的純物件），而 Element 是 Node 的一種。搞清楚它們的關係是理解 React 渲染流程的第一步。

三者關係

從大到小：Node ⊇ Element ← Component

名稱是什麼範例
React Node 任何可渲染的值：Element、字串、數字、null、陣列 'hello'、123、null、<div>...</div>
React Element 描述畫面的不可變純物件，由 JSX 或 createElement 建立 { type: 'h1', props: { children: 'Hi' }, ... }
React Component 接收 props、回傳 Element 的函式或類別（可複用的 UI 樣板） function Button(props) { return <button>...</button>; }
重點區辨

Element 是描述，Component 是工廠

// Component：函式，可複用
function Greeting({ name }) {
  return <h1>Hello, {name}</h1>;  // 回傳 Element
}

// Element：呼叫 Component 後得到的純物件描述
const el = <Greeting name="Yenyu" />;
// el = { type: Greeting, props: { name: 'Yenyu' }, ... }
Element 是輕量的「快照描述」，React 拿它和舊 Element 比對（diffing）後，才決定要不要更新真正的 DOM。
延伸追問

面試官可能再追

Element 和 DOM 節點有什麼關係？

Element 只是 JS 物件，是「想要什麼」的描述；真正的 DOM 節點由 React DOM 根據 Element 建立和更新，兩者是不同層的東西。

為什麼 Element 設計成不可變（immutable）？

不可變讓 React 可以用引用比較（reference equality）快速判斷是否需要重新渲染，也讓狀態變化更可預測。

面試這樣答

30 秒版本

「React Node 是任何可渲染的值（字串、數字、Element 等）；React Element 是 JSX 或 createElement 產生的不可變純物件，描述要渲染什麼；React Component 是接收 props、回傳 Element 的函式或類別，是可複用的 UI 工廠。簡單說：Component 是食譜，Element 是做好的菜描述，Node 是廣義可上桌的任何食物。」
