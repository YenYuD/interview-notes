REACT 除錯

四層除錯工具箱：從React DevTools 到錯誤邊界

有效除錯 React 應用需要工具分層配合：React DevTools 看組件樹和 state、斷點暫停執行查看流程、console.log 快速追蹤、錯誤邊界捕獲渲染錯誤並顯示備用 UI。

錯誤邊界

捕獲渲染錯誤，顯示備用 UI

// 方法一：手寫 Class Component 錯誤邊界
class ErrorBoundary extends React.Component {
  state = { hasError: false };

  static getDerivedStateFromError() {
    return { hasError: true };
  }

  componentDidCatch(error, info) {
    // 上報錯誤到監控服務（如 Sentry）
    console.error(error, info);
  }

  render() {
    return this.state.hasError
      ? <h1>發生錯誤，請重新整理。</h1>
      : this.props.children;
  }
}

// 方法二：用 react-error-boundary 套件（更靈活）
import { ErrorBoundary } from 'react-error-boundary';

<ErrorBoundary
  FallbackComponent={ErrorFallback}
  onReset={() => { /* 重置 app state */ }}
  onError={(error, info) => logToSentry(error, info)}
>
  <App />
</ErrorBoundary>
⚠️

錯誤邊界只能捕獲渲染過程中的錯誤，無法捕獲事件處理器、非同步程式碼（setTimeout、fetch）中的錯誤。後者需用 try-catch 或 useErrorBoundary hook 手動拋出。

延伸追問

面試官可能再追

React DevTools 的 Profiler 能幫助解決什麼問題？

Profiler 錄製一次互動後，會顯示每個組件的渲染持續時間、渲染次數，以及「為什麼這個組件重渲」（props 變了？context 變了？父組件重渲？）。這讓你精確定位效能瓶頸，而不用猜測。

事件處理器裡的錯誤要怎麼讓錯誤邊界捕獲？

用 react-error-boundary 的 useErrorBoundary hook 取得 showBoundary，在 catch 裡呼叫 showBoundary(error) 手動把錯誤傳給最近的錯誤邊界。
