依賴陣列決定 effect 「何時再跑一次」

第二個參數三種寫法，行為天差地別：沒寫陣列（每次都跑）、空陣列（只跑一次）、有依賴（依賴變才跑）。寫錯就會 effect 狂跑或抓到舊值。

面試官可能再追

cleanup 函式什麼時候跑？

effect 回傳的函式會在「下次 effect 執行前」與「組件卸載時」執行，用來清訂閱、清計時器、abort 請求，避免洩漏。

依賴是物件/陣列時老是重跑？

因為淺比較比的是引用，每次渲染新建的物件引用都不同。用 useMemo 穩定它，或只依賴其中的原始值欄位。
