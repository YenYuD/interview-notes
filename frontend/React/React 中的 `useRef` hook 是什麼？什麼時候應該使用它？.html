useRef：存東西但不觸發重渲，或直接操作 DOM

useRef 回傳一個 { current: value } 物件，它的值改變時不會觸發重新渲染。有兩大用途：直接存取 DOM 元素，以及在渲染間保存可變值（如 timer ID、前一次的 state）。

兩大用途

DOM ref vs 可變值儲存

// 用途一：存取 DOM 元素
function FocusInput() {
  const inputRef = useRef(null);
  useEffect(() => { inputRef.current?.focus(); }, []);
  return <input ref={inputRef} />;
}

// 用途二：跨渲染儲存值（不觸發重渲）
function Timer() {
  const timerRef = useRef(null);

  const start = () => {
    timerRef.current = setInterval(() => console.log('tick'), 1000);
  };
  const stop = () => clearInterval(timerRef.current);

  return <><button onClick={start}>開始</button><button onClick={stop}>停止</button></>;
}
useRef vs useState

選哪個的判斷標準

useState值改變需要更新畫面 → 用 state
useRef值改變不需要更新畫面 → 用 ref（如 timer ID、前一次值）
⚠️

不要把 useRef 當作 state 的替代——如果你需要 React 對值的改變有所反應（重渲、顯示在 UI 上），那就是 useState 的工作。

延伸追問

面試官可能再追

useRef 和 createRef 有什麼差別？

createRef 每次渲染都建立新物件；useRef 在組件整個生命週期回傳同一個物件。在功能組件內應用 useRef；createRef 是類別組件的舊版方式。

在 useEffect 裡讀取 ref.current 需要加到依賴陣列嗎？

不需要，React 保證 ref 物件穩定（引用不變）。但 ref.current 的值不受 React 追蹤，若需依賴它的值觸發 effect，要用 state 而非 ref。
