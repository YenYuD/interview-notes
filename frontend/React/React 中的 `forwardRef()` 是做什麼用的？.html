forwardRef：讓父組件的 ref 能穿透自訂組件，直達 DOM

預設情況下，父組件無法用 ref 直接存取子函式組件內部的 DOM。forwardRef 讓自訂組件把父層傳來的 ref「轉送」給內部的 DOM 元素或類別組件實例。

為什麼需要它

問題：ref 傳進功能組件會消失

// 沒有 forwardRef 時，這樣寫 ref 是 null
function MyInput(props) {
  return <input {...props} />;
}

const ref = useRef();
<MyInput ref={ref} />  // ⚠️ ref.current 是 null！

// 用 forwardRef 包裝後，ref 轉發到 input
const MyInput = forwardRef((props, ref) =>
  <input ref={ref} {...props} />
);
// 現在 ref.current 指向真正的 <input> DOM 元素
完整範例

父組件點按鈕、聚焦子組件的 input

const FancyInput = forwardRef((props, ref) => (
  <input className="fancy" ref={ref} {...props} />
));

function Form() {
  const inputRef = useRef();

  return (
    <>
      <FancyInput ref={inputRef} placeholder="輸入..." />
      <button onClick={() => inputRef.current?.focus()}>
        聚焦
      </button>
    </>
  );
}
ℹ️

React 19 起，ref 可以作為普通 prop 傳遞，不再需要 forwardRef 包裹。但了解 forwardRef 仍是面試必備，因為大量現有程式碼仍在使用。

延伸追問

面試官可能再追

forwardRef 可以搭配 useImperativeHandle 嗎？

可以，而且這是進階用法：useImperativeHandle 讓你自定義 ref 暴露的 API（而非整個 DOM），例如只暴露 focus() 和 reset() 兩個方法，隱藏其餘 DOM 屬性。

類別組件需要 forwardRef 嗎？

不需要，類別組件本身就可以直接接收 ref，ref.current 指向組件實例。forwardRef 只是為了功能組件。

面試這樣答

30 秒版本

「forwardRef 讓功能組件能把父層傳來的 ref轉發給內部的 DOM 元素。預設情況下，ref 傳入功能組件會是 null，因為函式沒有實例。用 forwardRef 包裹後，組件接收第二個參數 ref，再把它附到目標元素。常見用途是設計可複用的 Input、Modal 等組件，讓呼叫者能直接操作 DOM（如聚焦、捲動）。」
