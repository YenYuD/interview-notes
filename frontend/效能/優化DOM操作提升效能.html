前端效能

DOM 碰越少越好，碰一次解決所有事

每次直接操作 DOM，瀏覽器就可能重新計算樣式和版面。減少次數、批次寫入、分開讀寫——是讓 DOM 操作高效的三個核心原則。

四招核心技巧

讓 DOM 操作盡量少觸發重排

💡

快取 DOM 參考：把 getElementById 結果存進變數，避免重複查詢，每次查詢都有代價。

// ✅ 只查一次，後續直接用變數
const el = document.getElementById('box');
el.style.color = 'red';
el.style.fontSize = '16px';
💡

DocumentFragment 批次插入：先在記憶體裡建好所有節點，最後一次插入 DOM，只觸發一次重排。

// ✅ 100 個元素只觸發一次 reflow
const frag = document.createDocumentFragment();
for (let i = 0; i < 100; i++) {
  const div = document.createElement('div');
  div.textContent = i;
  frag.appendChild(div);
}
document.body.appendChild(frag); // 只碰一次真實 DOM
最關鍵技巧

分開讀取與寫入，避免 Layout Thrashing

錯誤迴圈裡讀寫交錯
正確先批次讀，再批次寫
// ❌ 每次寫後立刻讀，強迫同步重排
items.forEach(el => {
  el.style.height = el.offsetHeight + 10 + 'px'; // 讀+寫
});

// ✅ 先讀完，再寫完
const heights = items.map(el => el.offsetHeight); // 批次讀
items.forEach((el, i) => el.style.height = heights[i] + 10 + 'px');
動畫場景

requestAnimationFrame 對齊重繪週期

動畫邏輯放進 requestAnimationFrame，確保每一幀的更新都在瀏覽器「準備重繪」時進行，不掉格、不浪費。

function animate() {
  // 動畫邏輯
  requestAnimationFrame(animate);
}
requestAnimationFrame(animate);
比 setTimeout(fn, 16) 精準：隱藏分頁時自動暫停、不累積誤差。
延伸追問

面試官可能再追

cssText 和逐條設 style 的差別？

逐條設 el.style.color、el.style.fontSize 可能觸發多次樣式計算；el.style.cssText = 'color:red;font-size:16px' 一次設完，減少中間步驟。另一個常見做法是改 className，讓瀏覽器一次套用整組 CSS。

React / Vue 怎麼解這個問題？

框架用虛擬 DOM 在記憶體中比對差異（diffing），批次計算出最小化的真實 DOM 操作集合後一次寫入，開發者不需手動管理讀寫順序。

面試這樣答

30 秒版本

「優化 DOM 操作的核心是減少觸發重排的次數。我會：快取 DOM 參考避免重複查詢；用 DocumentFragment 批次插入節點；把讀取（offsetHeight）集中在寫入之前，避免 layout thrashing；動畫用 requestAnimationFrame 對齊重繪週期。能用框架的虛擬 DOM 就交給框架管，自己寫原生時這幾點最重要。」
