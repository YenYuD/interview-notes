Jest、Mocha、Jasmine、Cypress：各司其職，別全選

四大框架各有設計哲學：Jest 求一站式，Mocha 求彈性，Jasmine 求 BDD 可讀，Cypress 求真實瀏覽器。搞清楚定位，面試不慌。

各框架核心賣點

J

Jest — React 生態系標配

Facebook 出品，零配置即可使用。快照測試（snapshot testing）是亮點——一行程式碼捕捉元件輸出，下次渲染若偷偷變動馬上抓到。內建 jest.fn()、jest.mock()，不需額外安裝。

M

Mocha — 自由組合派

只是測試執行器，本身不帶斷言或 mock。與 Chai（斷言）+ Sinon（mock/spy）是黃金組合。彈性最高，適合有特殊需求的函式庫或後端服務。

Ja

Jasmine — BDD 語意清晰

語法強調「行為描述」：describe / it / expect 念起來像英文句子。Angular CLI 預設採用。無外部依賴，特別適合教學環境。

Cy

Cypress — 端對端體驗最佳

跑在真實 Chrome 裡，每步操作都有截圖可回溯。自動等待讓 E2E 測試不再充斥 waitFor。適合驗證整個使用者流程，而非單一函式邏輯。

延伸追問

面試官可能再追

新專案 2024 年該選哪個？

React/Node 新專案：Jest（或 Vitest for Vite 生態）+ Cypress/Playwright for E2E。不需要 Mocha 或 Jasmine 除非有特殊理由。

快照測試（Snapshot Testing）是什麼？有什麼缺點？

Jest 會把元件渲染結果存成文字快照，之後每次測試比對是否一致。優點是不費力捕捉迴歸；缺點是開發者習慣直接 -u 更新快照，快照變成形式審查，失去保護力。

面試這樣答

30 秒版本

「熱門框架我會這樣分：Jest 是 React 生態的首選，內建斷言和 mock，零配置就能跑。Mocha 的賣點是彈性，可以自由搭 Chai 和 Sinon，適合有客製需求的後端。Jasmine 以 BDD 語意著稱，是 Angular 預設。Cypress 專攻 E2E，在真實瀏覽器跑，時間旅行除錯很好用。新專案我傾向 Jest + Cypress 組合。」
