子元素一浮動，父層就塌了

浮動元素會脫離流，導致父容器高度算成 0、整個塌掉。解法是讓父層形成一個 BFC（區塊格式化上下文）——一個能「框住」內部浮動的獨立排版環境。

怎麼形成 BFC

滿足任一條件就會建立

  • float 不為 none
  • position 為 absolute 或 fixed
  • display 為 inline-block / flex / grid / table-cell 等
  • overflow 不為 visible（最常用的觸發手段：overflow:hidden 或 auto）
💡

BFC 還有第二個用途：阻止 margin 摺疊。同一個 BFC 內相鄰區塊的垂直 margin 會摺疊，但 BFC 會擋住它與外部元素之間的摺疊。

延伸追問

面試官可能再追

現在還會用 overflow:hidden 清浮動嗎？

清浮動的經典手段，但副作用是會裁切溢出內容。現代版面多改用 Flexbox / Grid，根本不用浮動，也就不需要清。要清浮動時 clearfix（::after { clear: both }）也是常見做法。

BFC 和 margin 摺疊有什麼關係？

BFC 是個「封閉」環境：內部 margin 可摺疊，但不會跟外部摺疊。把元素放進獨立 BFC，就能避免它的 margin 意外和外層合併。

面試這樣答

30 秒版本

「BFC 是一個獨立的區塊排版環境。它最重要的特性是能包住內部的浮動元素，避免父層高度塌陷，也能阻止 margin 跟外部摺疊。觸發方式有 overflow:hidden、display:flex/grid、浮動、絕對定位等。實務上現代版面用 Flex/Grid，已經很少遇到要靠 BFC 救塌陷的情況了。」
