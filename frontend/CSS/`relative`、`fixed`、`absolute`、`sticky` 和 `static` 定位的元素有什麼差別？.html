五種一次看懂

值相對誰定位佔原位？
static正常流（top/left 無效）佔
relative自己原本的位置佔（留下空位）
absolute最近的已定位祖先不佔（脫離流）
fixed視窗 viewport不佔（捲動不動）
sticky到臨界值前像 relative，之後像 fixed佔
💡

absolute 的「最近已定位祖先」是關鍵——所以常見手法是給父層加 position:relative，當作子層絕對定位的座標原點。

延伸追問

面試官可能再追

sticky 沒生效，為什麼？

常見原因：沒設定位方向（要有 top 等）、父層有 overflow:hidden/auto 把它的黏附範圍裁掉、或父層高度不足以讓它「黏」。

absolute 和 fixed 差在哪？

參考系不同：absolute 相對「最近已定位祖先」，fixed 相對「視窗」，所以 fixed 捲動時固定不動，常用於回到頂部按鈕、固定導覽列。

面試這樣答

30 秒版本

「我會用兩個問題區分：相對誰、佔不佔位。static 是預設、走正常流；relative 相對自己微調但保留原位；absolute 脫離流、相對最近已定位祖先；fixed 相對視窗、捲動不動；sticky 是 relative 與 fixed 的混合，超過臨界值才黏住。實務上常用『父 relative ＋ 子 absolute』來定位。」
