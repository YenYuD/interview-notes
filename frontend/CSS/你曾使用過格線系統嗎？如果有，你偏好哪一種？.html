從 float 格線到 CSS Grid——格線系統的三代演進

CSS 格線系統從 float 時代演進到 Flexbox，再到原生 CSS Grid。現代專案不再需要框架格線——理解每個工具的適用場景才是核心能力。

三代演進

格線系統的發展歷史

Float 格線時代（~2014） Bootstrap 2/3 用 float 實作 12 欄格線，需要 clearfix，計算百分比寬度。瀏覽器支援最廣但維護複雜。
Flexbox 格線（2014~） Bootstrap 4 改用 Flexbox。一維排版更直觀，對齊控制容易，瀏覽器支援率現已達 99.6%。現代的首選框架格線。
原生 CSS Grid（現代） 真正的二維格線——同時控制行和列。不需要框架即可實現複雜版面，Tailwind 等框架也提供 Grid utility class。
選擇建議

Flexbox vs Grid 各自的強項

用 Flexbox 一維排版（導覽列、按鈕組、卡片行）；動態內容數量不固定；沿主軸對齊分散
用 CSS Grid 二維版面（整頁佈局、儀表板、圖片牆）；需要精確控制行列對齊；固定格線結構
💡

Flexbox 和 Grid 並非互相排斥，常見做法是用 Grid 做頁面整體佈局（header/sidebar/main/footer），再用 Flexbox 處理元件內部的對齊。

延伸追問

面試官可能再追

CSS Grid 的 fr 單位是什麼？

fr 是「fractional unit」，代表可用空間的比例份額。grid-template-columns: 1fr 2fr 表示第一欄佔剩餘空間的 1/3，第二欄佔 2/3，會自動適應容器寬度，比百分比更靈活（因為 fr 在扣除 gap 後才計算）。

面試這樣答

30 秒版本

「格線系統從 float 時代演進到 Flexbox，再到原生 CSS Grid。現在我不再用框架格線——Flexbox 處理一維排版（導覽、元件內部對齊），CSS Grid 處理二維版面（整頁佈局、儀表板）。CSS Grid 的 fr 單位和 grid-template-areas 讓複雜版面變得非常直觀，比 float 的百分比計算優雅太多。如果要用框架，Tailwind 的 grid utility 也很完善，不需要額外引入格線系統。」
