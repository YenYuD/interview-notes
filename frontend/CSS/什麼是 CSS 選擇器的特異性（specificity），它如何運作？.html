樣式沒生效，不是被覆蓋是被「贏」掉

多條規則打架時，瀏覽器用「特異性」算分數決勝。記法是三欄：ID － CLASS － TYPE。高位永遠壓低位，再多低位也追不回。

ID － CLASS － TYPE

欄位算什麼例

⚠️

順位最高的其實是 !important > 行內 style > 特異性。特異性相同時，CSS 中最後出現的那條贏。

✅

最佳實務：盡量寫低特異性的選擇器，之後才容易覆寫、不用被迫動用 !important。

延伸追問

面試官可能再追

:not() 或 :is() 怎麼算？

:is() / :not() 本身不計分，取其括號內特異性最高的那個參數來算。:where() 則永遠是 0，很適合寫低特異性的基底樣式。

通用選擇器 * 算幾分？

* 和組合符（+ > ~）特異性都是 0。

面試這樣答

30 秒版本

「特異性是瀏覽器在多條規則衝突時的計分制，分三欄 ID－CLASS－TYPE，高位壓低位。完整順位是 !important > 行內 > 特異性 > 來源順序。我會刻意維持低特異性、少用 ID 當樣式鉤子、避免 !important，這樣樣式才好維護、好覆寫。」
