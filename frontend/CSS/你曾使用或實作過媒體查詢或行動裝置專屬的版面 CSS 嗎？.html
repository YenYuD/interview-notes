CSS / 響應式

媒體查詢：不只是斷點，也是行為切換的開關

媒體查詢讓同一套 CSS 在不同裝置條件下呈現不同版面。從傳統的寬度斷點，到現代的偏好設定查詢（暗色模式、減少動態），媒體查詢的應用範圍遠超響應式版面。

實作案例

行動端版面切換的典型場景

/* 行動優先：先定義行動端樣式 */
.nav {
  display: flex;
  flex-direction: column;  /* 行動：垂直堆疊 */
  position: fixed;
  bottom: 0;
}

/* 桌機：水平導覽列 */
@media (min-width: 768px) {
  .nav {
    flex-direction: row;
    position: static;
    border-bottom: 1px solid #eee;
  }
}
實際案例：將行動端堆疊藥丸導覽列（bottom navigation），在超過 768px 斷點後切換為水平固定頂端的分頁導覽列。
現代媒體查詢

不只是尺寸斷點

prefers-color-scheme 偵測作業系統暗色模式設定
prefers-reduced-motion 偵測使用者偏好減少動畫（前庭障礙無障礙）
hover: none 偵測裝置不支援 hover（觸控裝置）
print 列印時隱藏導覽、顯示連結 URL
延伸追問

面試官可能再追

min-width 和 max-width 哪個更推薦？

行動優先策略用 min-width（基礎樣式是行動端，再用 min-width 往上覆蓋）；桌機優先用 max-width（反過來）。現代開發推薦行動優先，因為行動裝置比例越來越高，且行動端樣式作為預設更簡潔。

Tailwind 的 sm/md/lg/xl 斷點是怎麼設計的？

Tailwind 採用行動優先：無前綴的 class（如 flex）是所有尺寸都套用；加前綴（如 md:flex）表示在 md 斷點（768px）以上才套用。這讓行動端樣式是預設，桌機樣式是覆蓋，符合行動優先原則。

面試這樣答

30 秒版本

「有實作過響應式版面，主要用行動優先策略：先定義行動端樣式，再用 min-width 媒體查詢在更大視口覆蓋。典型案例是把行動端的底部固定導覽，在平板以上切換為水平頂部導覽列。現代媒體查詢我也會用 prefers-color-scheme 支援暗色模式、prefers-reduced-motion 照顧前庭障礙使用者，這些都是現代前端的標準實踐。」
