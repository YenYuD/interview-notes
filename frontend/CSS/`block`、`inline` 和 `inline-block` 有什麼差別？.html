重點記憶

inline 的垂直限制

⚠️

inline 元素的垂直 padding/border 雖然視覺上會顯示（佔住周圍顏色），但不影響行間距，不會推開上下行的其他元素，這是最常踩的坑。需要垂直間距時，改用 inline-block。

float 後 inline 的變化 inline 元素加了 float 後，行為會接近 block——可設定垂直 margin/padding
延伸追問

面試官可能再追

inline 元素之間為什麼有空白間隙？

HTML 中相鄰的 inline 元素（如 <img>）若換行書寫，空白字元會被渲染成一個空格。解法：父元素 font-size: 0（再在子元素設回），或改用 flex/grid 排版。

什麼時候用 inline-block 而不用 flex？

單一獨立元件需要並排且設尺寸時用 inline-block（如按鈕、徽章）；需要對容器內的一群子元素進行對齊、排序、間距等複雜控制時，flex 更合適也更語意清晰。

面試這樣答

30 秒版本

「三種模式最大差別在兩點：一是是否獨佔一行，block 會；二是能否設定 width/height，inline 不能。inline-block 是折衷——可以與文字並排，同時又能設定尺寸和垂直 margin。實際上 inline 的垂直 padding 雖然視覺顯示，但不影響行距，這點最容易踩坑。」
