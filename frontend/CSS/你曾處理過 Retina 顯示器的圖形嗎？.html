CSS / 響應式圖形

高 DPI 螢幕讓圖片模糊——srcset 是現代解法

Retina（高像素比）螢幕若顯示普通解析度圖片，會出現模糊。解法是提供多解析度版本讓瀏覽器自動選擇，或直接改用SVG——天生無損縮放。

核心概念

什麼是 Retina / 高像素比

Retina 是 Apple 的行銷術語，指 device pixel ratio（DPR）> 1 的螢幕。DPR=2 意思是：一個 CSS 像素由 2×2=4 個實體像素渲染。普通圖片會被拉伸而模糊。

現今幾乎所有行動裝置螢幕都是高 DPI（DPR 2-3），所以「Retina 處理」不只是 Mac 的問題。
解決方案

三種方法

1. srcset + sizes（首選） 
<img
  src="/img/photo-800.jpg"
  srcset="/img/photo-400.jpg 400w,
          /img/photo-800.jpg 800w,
          /img/photo-1200.jpg 1200w"
  sizes="(min-width: 768px) 50vw, 100vw"
  alt="範例"
/>
瀏覽器根據視口寬度和 DPR 自動選最合適的圖片。
2. 使用 SVG（圖示最佳解） SVG 是向量格式，無論任何 DPR 都清晰渲染，且可用 CSS 改色。圖示永遠優先使用 SVG。
3. CSS background-image 用 @media 用 min-resolution: 2dppx 媒體查詢，高 DPI 螢幕載入 2x 背景圖。
💡

不支援 srcset 的極舊瀏覽器（IE11）會直接使用 src 的備用圖，符合漸進增強原則，不需要特別處理。

延伸追問

面試官可能再追

srcset 中的 w 描述符和 x 描述符有什麼差別？

w 描述符（如 400w）指圖片的實際像素寬度，需要配合 sizes 讓瀏覽器計算最佳選擇，更靈活。x 描述符（如 2x）直接對應 DPR，適合固定尺寸的圖片（圖示、頭像），寫法更簡單。

<picture> 元素和 srcset 有什麼不同？

srcset 讓瀏覽器自動選擇最合適的解析度版本。<picture> 讓開發者完全控制——可針對不同裝置提供完全不同的圖片（art direction），如手機顯示裁切版、桌機顯示全版，或提供 WebP 格式而舊瀏覽器退回 JPEG。

面試這樣答

30 秒版本

「Retina 指 DPR > 1 的高像素比螢幕，普通圖片在上面顯示會模糊。解法一是用 srcset 提供多解析度版本讓瀏覽器自動選最合適的，搭配 sizes 考慮視口寬度；解法二是改用 SVG，向量格式本來就不失真，是圖示的最佳選擇。避免始終提供最高解析度——行動裝置浪費流量，高解析度圖片在普通螢幕也沒有可見差異。」
