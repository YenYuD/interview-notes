CSS

一個屬性決定元素如何佔據空間

display 是 CSS 最基礎也最關鍵的屬性，決定元素以何種「盒模型」呈現於文件流中。從 block、inline 到 flex、grid，選對 display 就選對了版面的骨架。

核心概念

display 常見值一覽

每個值決定元素如何在頁面佔位、能否設定尺寸、以及對周圍元素的影響。

值行為代表元素
block獨佔整行，可設寬高div、p、section
inline與文字並排，不可設寬高span、a、strong
inline-block並排但可設寬高按鈕、圖示
flex區塊容器 + flexbox 子軸控制導覽列、卡片列
grid區塊容器 + 二維格線控制整體頁面佈局
none從文件流中完全移除，不佔空間隱藏元素
table / table-cell模擬 table/td 行為古早版面技巧
list-item產生清單標記（bullet）li
重點提醒

常見混淆點

display: none 完全移除，子元素也不顯示，不佔空間
visibility: hidden 元素隱藏但仍佔空間，螢幕閱讀器通常忽略
inline 不能設寬高 設了 width/height 也無效；需要改用 inline-block
💡

現代版面幾乎都用 flex 或 grid，inline-block 則常見於按鈕與小元件；table-* 系列屬於老式技巧，新專案不推薦。

延伸追問

面試官可能再追

display: none 和 visibility: hidden 有什麼差別？

display: none 讓元素完全離開文件流，不佔任何空間，子元素也一起消失。visibility: hidden 只是讓元素不可見，但仍佔據原本空間，子元素可個別設 visibility: visible 來重新顯示。

inline-block 和 flex 都能並排，應該怎麼選？

單一元素需要並排且設尺寸時用 inline-block；需要排版一組子元素（對齊、間距、換行）時用 flex，更強大且語意更清楚。

flex 和 inline-flex 的差別？

flex 容器本身是 block 級別（獨佔一行）；inline-flex 容器本身是 inline 級別（可與文字並排），但內部子元素排版方式完全相同。

面試這樣答

30 秒版本

「display 屬性決定元素在文件流的佈局模式。block 獨佔一行、inline 與文字並排、inline-block 並排且可設尺寸；現代版面主要用 flex 處理一維排版、grid 處理二維排版。none 會讓元素完全脫離文件流，與 visibility: hidden（仍佔空間）不同。」
