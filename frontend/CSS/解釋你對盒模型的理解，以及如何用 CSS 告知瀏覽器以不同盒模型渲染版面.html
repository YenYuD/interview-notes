你設 width:100px，結果它佔了 130px

每個元素都是一個盒子：content + padding + border + margin。痛點在於——預設情況下 padding 和 border 會「加」在 width 之外，所以盒子比你想的胖。

面試官可能再追

border 和 margin 會重疊／摺疊嗎？

border 不會，每個元素各自渲染。margin 會「摺疊」，但只在垂直方向、區塊級元素之間——上下相鄰只取較大的那個，水平方向不摺疊。

沒設 height 的區塊元素多高？

等於內容高度 + padding。沒設 width 的非浮動區塊元素則會撐滿父層寬度（扣掉 padding），除非有 max-width。

面試這樣答

30 秒版本

「盒模型是 content + padding + border + margin。預設 content-box 下，width 只算內容，padding 和 border 會額外加上去，所以盒子常比預期胖。我習慣全域設 border-box，這樣 width 就包含 padding 和 border，量起來符合直覺。margin 不算盒子尺寸，只影響外部間距。」
