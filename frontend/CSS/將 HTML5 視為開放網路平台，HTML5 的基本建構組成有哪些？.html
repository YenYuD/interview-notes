HTML5 不只是標籤：開放網路平台的八個支柱

把 HTML5 理解為完整的開放網路平台，而不只是新標籤的集合。它涵蓋了從語意、多媒體、連線性到效能的八個核心能力維度。

核心概念

八個建構組成

維度說明代表技術
語意（Semantics）用標籤描述內容意義header、article、nav、section
樣式（Styling）自訂外觀，動畫效果CSS3、Transitions、Animations
連線性（Connectivity）新型伺服器通訊方式WebSocket、Server-Sent Events
離線與儲存客戶端本地資料儲存localStorage、IndexedDB、Service Worker
多媒體（Multimedia）原生影音支援video、audio、WebRTC
2D/3D 繪圖豐富視覺效果Canvas、SVG、WebGL
效能與整合速度優化、硬體利用Web Workers、requestAnimationFrame
裝置存取輸入輸出裝置整合Geolocation、Camera API、Touch Events
ℹ️

面試時用這八個維度來組織回答，能展現對 HTML5 的系統性理解，而不是只列舉幾個新標籤。

延伸追問

面試官可能再追

語意化標籤（semantic HTML）有什麼實際好處？

三大好處：1. SEO——搜尋引擎更理解內容結構；2. 無障礙性——螢幕閱讀器能正確識別導覽、主內容、標題層級；3. 可維護性——其他開發者讀 HTML 結構就能理解頁面組成，不需要全靠 div+class 猜。

Service Worker 和 localStorage 有什麼差別？

localStorage 同步、容量約 5MB、只能儲存字串，適合小型設定資料。Service Worker 是獨立執行緒，能攔截網路請求、快取資源，實現完整的離線功能（PWA 核心），功能遠比 localStorage 強大，但 API 較複雜。
