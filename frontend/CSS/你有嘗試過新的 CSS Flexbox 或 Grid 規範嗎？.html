一句話分工：Flex 管一條線，Grid 管一張表

Flexbox 是一維排版（一排或一列）；Grid 是二維排版（同時管列和欄）。選錯工具會多寫很多 CSS。

怎麼做完美置中？

Flex：display:flex; justify-content:center; align-items:center;。Grid 更短：display:grid; place-items:center;。

Grid 的 fr 和 auto-fill / minmax？

fr 是剩餘空間的比例單位。repeat(auto-fill, minmax(220px, 1fr)) 可做出「容器多寬就塞幾欄」的自適應卡片牆——本站索引頁就是這樣排的。
