float：仍在文件流中，卻讓父容器「看不見」它

float 讓元素浮靠左右、文字環繞，但父容器不會包住浮動子元素（高度塌陷）。clearfix 是解決高度塌陷的經典技巧。Flexbox/Grid 出現後，float 用於版面排版的場景大幅減少。

核心行為

float 和 position: absolute 的關鍵差異

float 仍在文件流中；周圍文字和行內元素會環繞它排列；父容器高度塌陷
position: absolute 完全脫離文件流；其他元素不感知它的存在；父容器更不會展開
⚠️

高度塌陷：若父容器內只有浮動子元素，父容器高度會縮為 0，後續元素會跑到錯誤位置。

清除浮動

Clearfix 技巧（經典解法）

/* 方法一：偽元素 clearfix */
.clearfix::after {
  content: '';
  display: block;
  clear: both;
}

/* 方法二：overflow（建立新 BFC） */
.parent {
  overflow: hidden; /* 或 overflow: auto */
}
方法三（現代）：直接改用 Flexbox 或 Grid，根本不需要 float，也不需要 clearfix。
延伸追問

面試官可能再追

float 還有哪些現代用途？

主要剩下「文繞圖」效果（文字環繞圖片），這是 Flexbox/Grid 原生不支援的排版效果。配合 shape-outside 還可以做不規則文字環繞。

CSS clear 屬性怎麼用？

clear: left 讓元素移到左浮動元素之下；clear: right 移到右浮動之下；clear: both 移到所有浮動元素之下。通常在需要「打斷浮動」的元素或容器的 ::after 偽元素上使用。

面試這樣答

30 秒版本

「float 讓元素靠左或靠右，行內內容會環繞它排列，但元素仍在文件流中，這點和 position: absolute 不同。主要問題是父容器高度塌陷——父元素不包住浮動子元素。解法是 clearfix（偽元素 ::after 加 clear: both）或對父元素設 overflow: hidden 建立新 BFC。現代版面我都用 Flexbox 或 Grid，float 只在「文繞圖」時才需要。」
