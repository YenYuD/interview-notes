不等全部載完——盡快顯示才是王道

漸進式渲染（Progressive Rendering）是一系列「盡快讓使用者看到內容」的技術集合。在行動網路不穩定的環境下，感知載入速度比真實載入速度更重要。

三大技術

漸進式渲染的主要手法

圖片延遲載入（Lazy Loading） 只載入視口內的圖片，使用者捲動到圖片附近時才載入。 
<!-- 現代原生支援 -->
<img src="photo.jpg" loading="lazy" alt="...">
優先顯示首屏內容（Critical CSS） 將首屏必要的 CSS 內嵌在 HTML 中（inline），其餘樣式非同步載入。讓首次有意義繪製（FMP）盡快發生。
非同步 HTML 片段（Async Fragments） 後端逐步串流輸出 HTML，瀏覽器邊接收邊渲染，不等整個頁面生成完。
現代技術

SSR 相關延伸技術

Streaming SSR 伺服器邊渲染邊串流 HTML，React 18 的 renderToPipeableStream 即此概念
Progressive Hydration SSR 頁面分優先順序注水，可互動區域先完成，非關鍵區域延後
Selective Hydration React 18 特性：使用者互動的元件優先完成 hydration
延伸追問

面試官可能再追

img loading="lazy" 和 JavaScript lazy loading 有什麼差別？

原生 loading="lazy" 由瀏覽器原生支援，無 JavaScript 開銷，且能在 DOM 解析時就決定是否延遲下載。JS 方案（IntersectionObserver）在老瀏覽器或 JS 失效時是備案，但現代瀏覽器 loading="lazy" 支援率已相當高，優先使用原生方案。

什麼是 Critical CSS？如何實作？

Critical CSS 是首屏渲染必要的最小 CSS 子集，應內嵌在 HTML <head> 中，讓首次渲染不需等外部 CSS 下載。工具如 critical（npm）可自動提取。其餘 CSS 用 <link rel="preload" as="style"> 非同步預載。
