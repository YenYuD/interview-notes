CSS / SVG

SVG 上色：呈現屬性和 CSS 誰說了算？

SVG 有自己的 fill、stroke 呈現屬性，但 CSS 的優先權更高。理解這個層級關係，才能正確用 CSS 動態改色、做 hover 效果。

核心概念

三種上色方式的優先順序

方式範例能被 CSS 覆蓋？
呈現屬性（Presentational Attribute）fill="purple"✓ 可被樣式表覆蓋
內聯樣式（Inline Style）style="fill: purple"✗ 最高優先，難覆蓋
外部/嵌入 CSS.icon { fill: blue; }— 樣式表本身
 
<!-- 呈現屬性：fill="purple" 可被 CSS 覆蓋 -->
<rect
  x="10" y="10" width="100" height="100"
  stroke="blue"
  fill="purple"
  fill-opacity="0.5"
  stroke-opacity="0.8" />

/* CSS 可以覆蓋呈現屬性 */
svg rect { fill: blue; } /* 會把 fill="purple" 覆蓋 */
💡

想讓 SVG 圖示顏色可由 CSS 動態控制（如 hover 改色），應使用呈現屬性或完全不設 fill，讓 CSS currentColor 繼承父元素顏色。

實用技巧

用 currentColor 讓圖示跟隨文字顏色

/* SVG 中設定 fill="currentColor" */
<svg viewBox="0 0 24 24">
  <path fill="currentColor" d="M..." />
</svg>

/* 父元素設色，圖示自動跟隨 */
.btn {
  color: var(--accent);  /* SVG fill 自動繼承此顏色 */
}
.btn:hover {
  color: var(--accent-dark);  /* hover 時圖示也自動改色 */
}

面試官可能再追

SVG 圖示用 img 標籤引入和內聯 SVG 有什麼差別？

<img src="icon.svg"> 引入的 SVG 是獨立文件，CSS 無法控制內部 fill/stroke 顏色。內聯 SVG（直接在 HTML 中放 <svg>）可以用 CSS 選取內部元素、動態改色，支援動畫、hover 效果，是現代圖示的最佳實踐。

SVG sprite 系統怎麼實作？

用 <symbol id="icon-name"> 定義圖形，隱藏在 HTML 頂部（display:none 的容器），需要時用 <svg><use href="#icon-name"/></svg> 引用。一次定義，多處使用，且仍可用 CSS 控制顏色。

面試這樣答

30 秒版本

「SVG 上色有三種方式。呈現屬性（如 fill="purple"）的優先順序低於 CSS 樣式，所以可以被外部 CSS 覆蓋；內聯 style 優先順序最高，難以覆蓋。實務上我偏好讓圖示用 fill="currentColor"，這樣父元素的 color 就能控制圖示顏色，hover 效果也能自然繼承，不需要另外寫 SVG 選擇器。」
