雪碧圖：用一張大圖減少 HTTP 請求的老式技巧

CSS 雪碧圖（CSS Sprites）將多張小圖合併成一張，用 background-position 「剪裁」出需要的部分。曾是圖示的主流解法，HTTP/2 普及後重要性下降，但面試仍會被問到。

核心原理

如何實作

用雪碧圖產生器（如 CSS Sprites Generator）將多張圖片打包成一張大圖
工具自動輸出各圖示的 CSS 座標與尺寸
套用 background-image + background-position 顯示對應區塊
/* 共用基底 */
.icon {
  background-image: url('spritesheet.png');
  width: 24px;
  height: 24px;
}
/* 各圖示用 background-position 定位 */
.icon-cart   { background-position: 0 0; }
.icon-arrow  { background-position: -24px 0; }
.icon-search { background-position: -48px 0; }
評估時機

現在還需要雪碧圖嗎？

雪碧圖的優點 減少 HTTP 請求（HTTP/1.1 下顯著）；預載 hover 狀態圖片，避免閃爍
現代替代方案 HTTP/2 多工解決了請求數問題；圖示改用 SVG 字體或 SVG symbol；圖示元件庫（如 Heroicons）
ℹ️

現代專案圖示首選 SVG 圖示系統（svg <use>、SVG sprite）或圖示字體（Icon Font）。點陣圖雪碧圖主要在 HTTP/1.1 環境或需要支援超舊瀏覽器時才考慮。

延伸追問

面試官可能再追

HTTP/2 為什麼讓雪碧圖變得較不必要？

HTTP/1.1 每個連線一次只能處理一個請求（有並行數限制），多張圖片請求會排隊等待。HTTP/2 支援多工（Multiplexing），在同一個連線上並行傳送多個請求，大幅減少了合併請求的需求。

SVG sprite 和點陣圖雪碧圖的差異？

SVG sprite 使用 <symbol> 定義圖形，用 <use href="#icon-id"> 引用，可縮放不失真、可用 CSS 改色。點陣圖雪碧圖是固定像素，縮放會模糊，且無法動態改色。

30 秒版本

「CSS 雪碧圖把多張小圖合成一張，用 background-position 剪裁出需要的部分，主要優點是減少 HTTP 請求。在 HTTP/1.1 時代這很重要，但 HTTP/2 的多工特性已讓這個需求大幅降低。現代專案我會優先用 SVG 圖示系統——可縮放、可改色、無需座標計算；點陣雪碧圖現在主要是面試考古題的範疇了。」
