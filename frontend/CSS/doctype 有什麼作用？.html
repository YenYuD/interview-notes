HTML / 瀏覽器渲染

一行宣告，讓瀏覽器進入標準模式而非猜測模式

DOCTYPE 告訴瀏覽器這份文件遵循哪個 HTML 版本規範，從而啟用標準模式（no-quirks mode）渲染。少了它，瀏覽器會用「怪異模式」亂猜，CSS 盒模型和渲染行為都會出錯。

核心概念

DOCTYPE 做了什麼

瀏覽器讀取文件第一行，找到 <!DOCTYPE html>
識別為 HTML5 規範 → 啟動標準模式（Standards Mode）
CSS 盒模型、JavaScript API、版面計算全部按規範執行 
<!-- HTML5 標準寫法：一定放在第一行 -->
<!DOCTYPE html>
<html lang="zh-Hant">
...
⚠️

沒有 DOCTYPE 或格式錯誤時，瀏覽器進入怪異模式（Quirks Mode）：盒模型計算不同、CSS 渲染不一致、JavaScript 行為出現差異，跨瀏覽器版面問題倍增。

歷史背景

為什麼 HTML5 的 DOCTYPE 這麼短？

舊版 HTML/XHTML 的 DOCTYPE 需要引用 DTD 完整 URL（超長字串）。HTML5 簡化為 <!DOCTYPE html>，純粹作為「啟用標準模式」的開關，不再需要指定外部 DTD。

舊版對比：
HTML 4.01：<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd">
延伸追問

面試官可能再追

怪異模式（Quirks Mode）具體有哪些不同？

最著名的是盒模型差異：怪異模式下 IE 將 border 和 padding 包含在 width 內（類似 border-box），而標準模式使用 content-box。此外還有行高計算、table 樣式等差異，各瀏覽器的怪異模式行為也不盡相同。

DOCTYPE 不區分大小寫嗎？

HTML5 的 DOCTYPE 宣告不區分大小寫，<!doctype html>、<!DOCTYPE HTML> 都有效。但慣例上使用 <!DOCTYPE html>（首字母大寫）。

面試這樣答

30 秒版本

「DOCTYPE 是 HTML 文件的第一行宣告，告知瀏覽器文件遵循的 HTML 版本。HTML5 的寫法是 <!DOCTYPE html>，它的作用是觸發瀏覽器進入標準模式（Standards Mode），確保 CSS 盒模型計算、版面渲染都按規範執行。沒有正確的 DOCTYPE，瀏覽器會進入怪異模式（Quirks Mode），各瀏覽器行為不一致，CSS 盒模型甚至計算方式都不同，會造成難以追蹤的跨瀏覽器 bug。」
