偽元素：不加 HTML 也能插入視覺內容

CSS 偽元素（pseudo-elements）讓你在不修改 HTML 結構的前提下，對元素的特定部分設定樣式或插入裝飾內容。::before、::after、::first-line 是最常用的三個。

常見偽元素

四個最實用的偽元素

偽元素用途典型應用
::before在元素內容前插入生成內容裝飾符號、工具提示箭頭
::after在元素內容後插入生成內容clearfix、引號裝飾
::first-line段落第一行的樣式排版裝飾
::first-letter段落第一個字母的樣式書籍首字放大
 
/* Clearfix：用 ::after 清除浮動 */
.clearfix::after {
  content: '';
  display: block;
  clear: both;
}

/* 工具提示的三角箭頭（不需要額外 HTML） */
.tooltip::after {
  content: '';
  border: 6px solid transparent;
  border-top-color: #333;
  position: absolute;
  bottom: -12px;
  left: 50%;
  transform: translateX(-50%);
}
偽元素 vs 偽類別

常被混淆的差別

偽元素 :: 雙冒號 針對元素的「某個部分」或插入生成內容：::before、::after、::first-line
偽類別 : 單冒號 根據元素的「狀態」選取：:hover、:focus、:nth-child()
💡

CSS3 規範才區分雙冒號（偽元素）和單冒號（偽類別）。為相容舊瀏覽器，舊有的 :before、:after 單冒號寫法大多數瀏覽器仍支援，但新程式碼應用 ::。

延伸追問

面試官可能再追

::before 和 ::after 需要 content 屬性嗎？

是的，::before 和 ::after 必須有 content 屬性（即使設為空字串 content: ''）才會在 DOM 中生成元素。缺少 content 則偽元素不存在，其他樣式也無效。

偽元素生成的內容在 DOM 中嗎？

不在標準 DOM 中（無法用 JavaScript querySelector 選取），但存在於渲染樹中，對螢幕閱讀器通常不可見（除非特別設定）。這就是為什麼它適合純裝飾用途，而非有語意的內容。

面試這樣答

30 秒版本

「偽元素讓我在不修改 HTML 的情況下，對元素特定部分設定樣式或插入裝飾內容。最常用的是 ::before 和 ::after，需要 content 屬性才生效。實際用途包括 clearfix（::after 加 clear: both）、工具提示的三角箭頭等——這些視覺裝飾不需要在 HTML 中加 div，保持了結構與樣式的關注點分離。注意偽元素用雙冒號 ::，偽類別（:hover）用單冒號。」
