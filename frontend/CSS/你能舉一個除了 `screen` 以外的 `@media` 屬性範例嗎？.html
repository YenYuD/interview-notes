CSS / 媒體查詢

@media 不只有 screen：四種媒體類型的完整圖像

@media 查詢不只用於響應式版面斷點。它支援四種媒體類型，讓樣式能針對不同輸出裝置（印表機、螢幕閱讀器）分別定義，是無障礙設計的重要工具。

四種媒體類型

@media 的完整分類

類型適用裝置常見用途
screen螢幕（電腦、平板、手機）響應式斷點、暗色模式
print印表機隱藏導覽列、調整字體為黑色
speech螢幕閱讀器（語音朗讀）針對語音輸出調整內容
all所有裝置（預設值）通用樣式（不指定類型時即為 all）
 
/* print：隱藏不需要印出的元素 */
@media print {
  .topbar, .nav, footer { display: none; }
  body { color: black; font-size: 12pt; }
  a::after { content: " (" attr(href) ")"; }
}
現代媒體特性

不只是類型：媒體特性查詢

ℹ️

現代 @media 更常用媒體特性（media features）而非類型，如 prefers-color-scheme（暗色模式）、prefers-reduced-motion（減少動態效果）、min-width（斷點）。

/* 暗色模式 */
@media (prefers-color-scheme: dark) {
  body { background: #1a1a1a; color: #eee; }
}

/* 減少動態效果（無障礙） */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
延伸追問

面試官可能再追

@media print 有哪些常見的實用技巧？

1. 隱藏導覽列、按鈕、廣告；2. 展開所有 details 元素（details { display: block; }）；3. 顯示連結完整 URL（a::after { content: " (" attr(href) ")" }）；4. 避免標題和內文分頁（h2 { page-break-after: avoid; }）。

@media 查詢可以組合嗎？

可以。用 and 組合條件：@media screen and (min-width: 768px)；用 ,（等同 or）：@media screen, print；用 not 否定：@media not print。

面試這樣答

30 秒版本

「@media 有四種類型：screen（螢幕）、print（印表機）、speech（螢幕閱讀器）、all（全部）。print 最實用：可以隱藏導覽列、設黑色字體、加顯連結 URL，讓頁面印出來好看。除了媒體類型，現代更常用媒體特性查詢，如 prefers-color-scheme: dark 支援暗色模式、prefers-reduced-motion 照顧前庭障礙用戶，這些都是無障礙設計的標準做法。」
