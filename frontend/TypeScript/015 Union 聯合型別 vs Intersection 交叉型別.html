| 是「或」，& 是「且」

Union B | C：值是其中一種，只能安全用共有屬性。Intersection B & C：值同時是兩者，所有屬性都要有。

DEMO — 哪些屬性能安全存取

切換 | 和 &，看可用屬性怎麼變

interface B { name: string; email: string; }
interface C { name: string; age: number; }
組合方式
直覺反過來：Union 是型別變「寬」、可用屬性卻變「窄」（只剩交集）；Intersection 是型別變「窄」、屬性卻變「全」（聯集）。
場景

各自用在哪

Union |Intersection &
意義是其中一種同時都是
可存取共有屬性（需 narrowing 才用各自的）全部屬性
典型用途參數接受多型別 string | number合併多個 interface
💡

用 Union 時，靠 narrowing（in、typeof、判別式聯合 discriminated union）縮型別後，才能安全存取各自獨有的屬性。

延伸追問

面試官可能再追

什麼是判別式聯合（discriminated union）？

給每個成員一個共同的字面量標籤欄位（如 type:'a'|'b'），用 switch(x.type) 縮窄，TS 就知道分支裡是哪個型別。是處理 Union 最好用的模式。

兩個有衝突屬性的型別做 & 會怎樣？

若同名屬性型別不相容（如 name:string 與 name:number），交叉後該屬性變成 never，實際上無法建立值。

面試這樣答

30 秒版本

「Union | 是『或』，值是其中一種，只能直接用共有屬性，要用各自的得先 narrowing；Intersection & 是『且』，值同時符合所有型別、擁有全部屬性。Union 常用在參數接受多型別，Intersection 常用來合併多個 interface。處理 Union 我會用判別式聯合來安全縮型別。」
