void 是「沒有回傳值」，never 是「永遠不會回傳」

一個字之差，概念天差地遠。void 代表函式正常結束但沒有回傳值；never 代表函式根本無法正常結束——它要不是拋出例外，就是進入無窮迴圈。

01

核心差異對比

voidnever
函式會結束？✅ 正常結束❌ 不會（拋錯 or 無窮）
實際值undefined不存在（無法被賦值）
可賦值給變數✅（值是 undefined）❌（never 是 bottom type）
典型使用場景console.log 等副作用函式throw 函式、無窮迴圈
02

程式碼對比

// void — 有執行完，但不回傳有意義的值
function log(msg: string): void {
  console.log(msg); // 執行完畢，回傳 undefined
}

// never — 一定拋錯，永遠到不了函式結尾
function fail(msg: string): never {
  throw new Error(msg);
}

// never — 無窮迴圈，也永遠回不來
function loop(): never {
  while (true) {}
}
03

never 的進階用途：Exhaustive Check

type Shape = "circle" | "square";

function getArea(shape: Shape): number {
  switch (shape) {
    case "circle": return Math.PI * 100;
    case "square": return 100;
    default:
      // 日後新增 "triangle" 卻忘了處理 → 此行編譯報錯
      const _check: never = shape;
      throw new Error(`Unhandled: ${shape}`);
  }
}
💡

Exhaustive Check 展示你讓型別系統在編譯期幫你抓 bug，不是等到 runtime 才發現漏掉了某個 case。面試加分點。

延伸追問

面試官可能再追

never 在 Union Type 中有什麼特殊行為？

never 在 union 中會自動消失：string | never → string。這也是 Exclude utility type 的核心機制——被條件型別標為 never 的成員會從 union 中消失。

void 和 undefined 有什麼差別？

void 是回傳型別（表示函式沒有有意義的回傳值），undefined 是值本身。void 型別的變數只能被賦值為 undefined，但用 void 更能表達「這個函式的回傳值不應被使用」的語義。

面試這樣答

30 秒版本

「void 表示函式正常結束但沒有回傳有意義的值，實際值是 undefined。never 表示函式永遠不會正常結束——要不是拋出例外，就是無窮迴圈。never 是 TypeScript 的底部型別，沒有任何值屬於它，且在 union 中會自動消失。進階用途是 exhaustive check：在 switch default 中把剩餘型別賦值給 never，若有漏掉的 case 就會在編譯期報錯。」
