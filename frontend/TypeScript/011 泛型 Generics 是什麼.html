泛型＝型別版的函式參數

函式參數讓你傳不同「值」；泛型 <T> 讓你傳不同「型別」。它比 any 精確、比重複定義乾淨——傳什麼型別進去，就保留什麼型別出來。

DEMO — any 丟掉型別，泛型留住型別

傳進去之後，TS 還認得它是什麼嗎？

兩種寫法
泛型在呼叫當下把 T 綁成實際型別（傳 string 就 T = string），所以回傳值仍是精確型別，IDE 自動補全、型別檢查都還在。
三個常用形態

函式、約束、介面

// 1. 泛型函式
function identity<T>(arg: T): T { return arg; }

// 2. 泛型約束：T 必須有 length
function len<T extends { length: number }>(x: T) { return x.length; }

// 3. 泛型介面
interface ApiResponse<T> { data: T; status: number; }
✅

你天天在用它：useState<T>、axios.get<T>()、Array<T>、Promise<T> 全都是泛型。

延伸追問

面試官可能再追

泛型約束（extends）做什麼？

限制 T 必須是某型別的子集，這樣函式內就能安全存取那些屬性（如 T extends { length:number } 才能讀 .length）。

泛型和 any 最大差別？

any 直接關閉型別檢查、回傳也是 any；泛型保留並串接型別資訊，傳入什麼回傳什麼，型別安全不打折。

面試這樣答

30 秒版本

「泛型是型別的參數，讓元件適用多種型別又保留型別安全。核心價值是在重用程式碼的同時保留型別精確度——傳 string 進去就回傳 string，不像 any 會把型別資訊丟掉。可搭配 extends 加約束。實務上 useState、axios.get、Promise 都是泛型。」
