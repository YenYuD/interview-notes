TYPESCRIPT

條件型別是型別層級的三元運算子，驅動所有 Utility Types

語法長得像 A extends B ? X : Y，讓你根據「型別是否符合條件」決定最終型別。Exclude、Extract、ReturnType 等內建工具的底層全都靠它。

01

基本語法與分配性

// 基本形式
type IsString<T> = T extends string ? "yes" : "no";

type A = IsString<string>;  // "yes"
type B = IsString<number>;  // "no"
type C = IsString<"hello">; // "yes"（字串字面量是 string 子型別）
ℹ️

分配性（Distributive）：當泛型 T 是 Union Type，條件型別會對每個成員分別運算。ToArray<string | number> 展開成 ToArray<string> | ToArray<number>。

02

內建 Utility Types 的底層實作

// Exclude — 從 T 中去掉可賦值給 U 的型別
type Exclude<T, U> = T extends U ? never : T;
type A = Exclude<"a" | "b" | "c", "a">; // "b" | "c"

// Extract — 從 T 中保留可賦值給 U 的型別
type Extract<T, U> = T extends U ? T : never;

// ReturnType — 取得函式的回傳型別（搭配 infer）
type ReturnType<T extends (...args: any) => any> =
  T extends (...args: any) => infer R ? R : any;

function getUser() { return { name: "Bob", age: 20 }; }
type User = ReturnType<typeof getUser>; // { name: string; age: number }
03

infer 關鍵字：在條件判斷中「捕捉」型別

type FirstArg<T> = T extends (first: infer F, ...rest: any[]) => any ? F : never;

function greet(name: string, age: number) {}
type Arg = FirstArg<typeof greet>; // string
infer 讓你在條件型別的「true 分支」中聲明一個待推斷的型別變數，TypeScript 會自動填入。這是 ReturnType、Parameters 等工具的核心。
延伸追問

面試官可能再追

什麼是條件型別的分配性？如何關閉？

泛型 T 是 union 時，條件型別對每個成員分別運算，結果再合成 union。要關閉分配性，把 T 包在 tuple 中：[T] extends [U] ? X : Y，這樣 T 就被當作整體處理。

NonNullable 的底層是什麼？

type NonNullable<T> = T extends null | undefined ? never : T。它利用分配性逐一去掉 null 和 undefined，剩下的型別組回 union。

面試這樣答

30 秒版本

「條件型別語法是 A extends B ? X : Y，意思是「若 A 是 B 的子型別，結果是 X，否則是 Y」。它是 TypeScript 型別系統的三元運算子，Exclude、Extract、ReturnType、NonNullable 等內建工具的底層都靠它。進階用法是搭配 infer——在條件判斷中捕捉並命名一個待推斷的型別，ReturnType 就是這樣實作的。日常開發不一定天天寫條件型別，但看懂 utility types 底層是必要的。」
