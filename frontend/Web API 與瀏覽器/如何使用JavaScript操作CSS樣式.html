JS 操作樣式：classList 優先，style 屬性備用

JavaScript 有多種方式修改元素的樣式，但最佳實踐是用 classList 切換預定義的 CSS 類別，保持關注點分離——樣式交給 CSS，邏輯交給 JS。

三種方式

從推薦到備用的順序

// 1. 推薦：切換 CSS 類別
el.classList.add('active');
el.classList.remove('hidden');
el.classList.toggle('dark-mode');

// 2. 動態計算的樣式：直接設 style 屬性
el.style.width = `${calculatedWidth}px`;
el.style.backgroundColor = userSelectedColor;

// 3. 全域主題：修改 CSS 變數
document.documentElement.style.setProperty('--primary-color', '#007bff');

// 讀取計算後樣式（包含繼承的）
const computed = getComputedStyle(el);
computed.getPropertyValue('--primary-color');
選擇原則

什麼情況用哪種方式

情況建議方式
狀態切換（active、hover、open）classList.toggle/add/remove
動態計算的值（使用者拖動設大小）element.style.xxx = value
全站主題顏色切換修改 CSS 自訂屬性（變數）
動態載入樣式表建立 link 元素並插入 head
💡

CSS 自訂屬性（--variable-name）是實現主題切換（dark mode）的最優雅方式：只改一個 CSS 變數，整頁樣式連帶更新。

延伸追問

面試官可能再追

getComputedStyle 和 element.style 有何不同？

element.style 只回傳內聯樣式（直接寫在 style 屬性的）；getComputedStyle() 回傳最終計算值，包含從 CSS 繼承的樣式，是唯讀的。

element.style.backgroundColor 和 CSS 的 background-color 命名有什麼差異？

CSS 屬性名用連字號（kebab-case），JS 的 style 物件用駝峰命名（camelCase）：background-color → backgroundColor。
