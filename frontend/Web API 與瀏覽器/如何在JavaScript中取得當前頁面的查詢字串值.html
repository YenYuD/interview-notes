WEB API 與瀏覽器

用 URLSearchParams 輕鬆解析 URL 查詢字串

過去要手動解析 ?page=2&sort=asc 這樣的查詢字串，現在用 URLSearchParams 一行就搞定。這是現代瀏覽器內建 API，不需要任何第三方函式庫。

基本用法

讀取、檢查、遍歷查詢參數

// URL: https://example.com?page=2&sort=asc&tag=js&tag=css
const params = new URLSearchParams(window.location.search);

// 讀取單一參數
params.get('page');      // "2"（字串，不是數字）
params.get('notExist'); // null

// 檢查參數是否存在
params.has('sort');      // true

// 讀取多重值
params.getAll('tag');    // ["js", "css"]

// 遍歷所有參數
params.forEach((value, key) => console.log(key, value));
修改查詢字串

URLSearchParams 也可以寫入

const params = new URLSearchParams();
params.set('page', '3');
params.append('tag', 'react');
params.delete('sort');

// 更新 URL 不觸發頁面重新載入（SPA 常見做法）
history.pushState({}, '', `?${params.toString()}`);
💡

params.get() 永遠回傳字串或 null，取得數字後需要自行轉型：Number(params.get('page')) 或 +params.get('page')。

延伸追問

面試官可能再追

URLSearchParams 和手動解析 location.search 有什麼差別？

URLSearchParams 自動處理 URL 編碼解碼（%20 轉空格等），以及多重值情況，手動解析需要自己處理這些邊界情況，容易有 bug。

React Router 等前端框架如何取得查詢字串？

React Router 提供 useSearchParams() hook，底層也是基於 URLSearchParams，但整合了路由狀態管理，修改參數時不需要直接操作 history API。

面試這樣答

30 秒版本

「取得查詢字串值最佳實踐是用 URLSearchParams：const params = new URLSearchParams(window.location.search)，然後用 params.get('key') 取值。它自動處理 URL 編碼，也支援 has() 檢查存在、getAll() 取多重值、set()/delete() 修改。要注意 get() 回傳的永遠是字串，需要數字要自行轉型。」
