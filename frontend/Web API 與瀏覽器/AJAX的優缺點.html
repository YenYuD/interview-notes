WEB API 與瀏覽器

AJAX：不重新載入頁面就能更新資料的技術

AJAX 讓網頁在背景向伺服器交換資料，只更新需要的部分，不必整頁刷新。現代實作幾乎都用 fetch() API，但掌握優缺點對面試至關重要。

核心概念

AJAX 是什麼？

AJAX（Asynchronous JavaScript and XML）是一種非同步通訊技術，讓頁面在不重新載入的情況下，於背景向伺服器發送與接收資料。實務上現在幾乎都用 JSON 而非 XML。

ℹ

傳統實作用 XMLHttpRequest，現代開發更常用 Promise-based 的 fetch()。

優缺點對照

什麼時候該用、什麼時候要小心

優點

部分頁面更新，體驗更流暢

優點

減少伺服器負載與頻寬消耗

優點

保留客戶端狀態（捲動位置、表單輸入）

缺點

依賴 JavaScript，禁用時失效

缺點

SEO 挑戰：搜尋引擎難以索引動態內容

缺點

書籤與瀏覽器前進/後退按鈕可能失效

⚠

若直接將伺服器回傳的 HTML 插入頁面而未做消毒，容易引發 XSS 安全漏洞。

面試官可能再追

AJAX 和 fetch() 有什麼關係？

AJAX 是概念，fetch() 是實作 AJAX 的現代工具。fetch() 基於 Promise，語法比 XMLHttpRequest 簡潔，也支援 async/await。

AJAX 如何解決 SEO 問題？

可採用伺服器端渲染（SSR）或預渲染（Prerendering），讓搜尋引擎爬取到完整 HTML，再由前端接管互動。

AJAX 的安全風險如何防範？

永遠對使用者輸入做消毒（sanitize）；避免把伺服器回傳的字串直接插入 innerHTML；使用 HTTPS 防止中間人攔截。
