WEB API 與瀏覽器

DOM：把 HTML 變成可以用 JavaScript 操作的樹狀結構

DOM（Document Object Model）是瀏覽器把 HTML 文件轉換成物件樹的結果，JavaScript 透過這個樹狀介面讀取、新增、刪除、修改頁面的任何部分。

樹狀結構

HTML 如何對應到 DOM 節點

HTML 文件：
<html>
  <head><title>Hello</title></head>
  <body>
    <h1>標題</h1>
    <p>段落</p>
  </body>
</html>

DOM 樹：
Document
  └── html
      ├── head → title → "Hello"
      └── body
          ├── h1  → "標題"
          └── p   → "段落"
節點類型

DOM 樹有哪些節點

節點類型說明範例
Document整個文件的根document
ElementHTML 標籤<div>、<p>
Text標籤內的文字"Hello World"
Attribute元素的屬性class="btn"
CommentHTML 註解<!-- ... -->
ℹ

DOM 不是 JavaScript 語言的一部分，而是瀏覽器提供的 Web API。Node.js 環境中沒有 DOM。

面試官可能再追

DOM 和 Virtual DOM 有什麼差別？

DOM 是瀏覽器維護的實際節點樹，直接修改效能較差；Virtual DOM 是 React 等框架在記憶體中維護的 DOM 複製品，比對變化後再批次更新真實 DOM，減少不必要的重排。

為什麼操作 DOM 很耗效能？

每次修改 DOM 可能觸發重排（reflow）和重繪（repaint）。重排要重新計算所有元素的位置和大小，代價很高。應批次修改、用 DocumentFragment，或讓框架來優化。
