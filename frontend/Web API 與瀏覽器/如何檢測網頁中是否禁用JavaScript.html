WEB API 與瀏覽器

用 <noscript> 為禁用 JavaScript 的使用者提供備援

當 JavaScript 被禁用時，<noscript> 標籤內的內容才會顯示。這是偵測 JS 狀態的唯一原生 HTML 方式，也是優雅降級（graceful degradation）的實踐。

noscript 用法

JS 啟用時完全隱藏，禁用時才顯示

<!DOCTYPE html>
<html lang="zh-Hant">
<head>
  <meta charset="UTF-8">
</head>
<body>
  <h1>歡迎使用我們的網站</h1>

  <!-- 只在 JavaScript 被禁用時才顯示 -->
  <noscript>
    <style>.noscript-warning { color: red; font-weight: bold; }</style>
    <p class="noscript-warning">
      您的瀏覽器已停用 JavaScript，部分功能可能無法正常運作。
    </p>
  </noscript>

  <div id="app"></div>
</body>
</html>
ℹ

<noscript> 也可以放在 <head> 中，用來在 JS 禁用時載入備用 CSS 或重新導向。

實際應用

三種常見的 noscript 用法

用途說明
提示訊息告知使用者需要啟用 JS 才能使用完整功能
備用樣式在 head 中放 noscript，載入非 JS 版本的樣式
分析追蹤Google Tag Manager 等工具的備用 <img> noscript 版本
💡

現代 SPA 通常在 <noscript> 裡放「請啟用 JavaScript 來使用本網站」的提示，因為整個 App 都依賴 JS 渲染。Next.js 等 SSR 框架則讓頁面在 JS 禁用時也能顯示基本內容。

延伸追問

面試官可能再追

有辦法在 JavaScript 程式碼內偵測 JS 是否啟用嗎？

不可能——因為 JS 被禁用時根本不會執行任何 JS 程式碼。noscript 是唯一原生的偵測方式，它是純 HTML 機制，不需要 JS 就能運作。

漸進式增強（Progressive Enhancement）和優雅降級（Graceful Degradation）有什麼差別？

漸進式增強：從最基本功能出發，再為能力更強的瀏覽器加功能；優雅降級：先做完整版，再為舊環境提供備案。前者更推薦，因為確保基礎功能對所有人可用。

面試這樣答

30 秒版本

「偵測 JavaScript 是否被禁用的方式是使用 <noscript> 標籤——它裡面的內容只在 JS 被禁用時才顯示，啟用時完全隱藏。因為 JS 禁用時不會執行任何 JS，所以這是唯一的純 HTML 偵測機制。實際應用包括顯示友善提示或提供備用內容，這也是優雅降級的一種實踐。」
