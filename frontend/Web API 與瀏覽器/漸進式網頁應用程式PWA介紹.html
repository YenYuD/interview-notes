WEB API 與瀏覽器

PWA：讓網頁像原生 App 一樣安裝、離線、推播通知

Progressive Web App 用標準網頁技術（HTML/CSS/JS）實現原生 App 的體驗。核心是 Service Worker（離線快取）+ Web App Manifest（安裝到主畫面）+ HTTPS。

三大核心技術

缺一不可的 PWA 基礎

Service Worker

背景腳本，攔截網路請求、管理快取，實現離線功能與推播通知

Web App Manifest

JSON 設定檔，定義名稱、圖示、啟動 URL，讓使用者安裝到主畫面

HTTPS

Service Worker 必要條件，確保安全性（localhost 例外用於開發）

Service Worker 快取

攔截請求 → 快取 → 離線可用

// 1. 在主腳本中註冊
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/sw.js');
}

// 2. sw.js：攔截 fetch 請求，先查快取再上網
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then(
      (cached) => cached || fetch(event.request)
    )
  );
});
特性說明
離線使用Service Worker 快取靜態資源
安裝到主畫面manifest.json 提供 App 元資料
推播通知Service Worker + Push API
背景同步離線時的操作，上線後自動同步

面試官可能再追

PWA 和原生 App 還有什麼差距？

PWA 無法存取某些原生 API（藍牙、NFC 有限制）；iOS 支援較差（Safari 對 Service Worker 的支援落後 Chrome）；沒有 App Store 曝光優勢；硬體整合（相機、GPS）功能受限。

Service Worker 的生命週期是什麼？

三個階段：安裝（install）→ 快取靜態資源；啟動（activate）→ 清理舊快取；抓取（fetch）→ 攔截請求。新版 SW 在所有分頁關閉前不會取代舊版。
