WEB API 與瀏覽器

Fetch API：Promise-based 的現代 HTTP 請求標準

fetch() 是現代瀏覽器內建的 HTTP 請求 API，回傳 Promise，支援 async/await，語法簡潔。但要記住一個大陷阱：HTTP 錯誤不會自動 reject。

基本用法

GET 與 POST 請求模式

// GET 請求（async/await 風格）
async function fetchUser(id) {
  const res = await fetch(`/api/users/${id}`);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}

// POST 請求（傳送 JSON）
await fetch('/api/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Alice', age: 25 }),
});
⚠

fetch() 只有網路失敗才 reject，HTTP 404/500 仍然 resolve，必須手動檢查 response.ok 或 response.status。

延伸追問

面試官可能再追

如何取消一個進行中的 fetch 請求？

用 AbortController：建立 controller，把 controller.signal 傳入 fetch options，呼叫 controller.abort() 即可取消，fetch 的 Promise 會以 AbortError reject。

fetch 如何帶 Cookie？

預設 fetch 不帶 Cookie。加上 credentials: 'include' 才會帶上跨域 Cookie；同源時用 credentials: 'same-origin'（預設行為）。
