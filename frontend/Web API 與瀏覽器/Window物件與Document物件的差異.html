WEB API 與瀏覽器

window 是瀏覽器視窗，document 是視窗裡的頁面內容

window 是 JavaScript 在瀏覽器中的全域物件，所有全域變數都掛在它上面；document 是 window.document 的簡寫，代表當前頁面的 DOM 結構。

延伸追問

面試官可能再追

在 Node.js 中有 window 嗎？

沒有。Node.js 的全域物件是 global，不是 window。document 也不存在，因為 Node.js 沒有 DOM。

為什麼 var 宣告的全域變數會掛在 window 上，let/const 不會？

var 是函式作用域，在全域作用域宣告時會成為 window 屬性；let/const 是區塊作用域，存在「腳本作用域」中，不會附加到 window 上。

30 秒版本

「window 是瀏覽器的全域物件，代表整個視窗環境，所有全域變數、計時器、導向方法都掛在它上面；document 是 window.document 的屬性，代表頁面的 HTML 文件結構，提供操作 DOM 的方法。簡單說：window 管『瀏覽器』，document 管『頁面內容』。」
