事件監聽器：addEventListener 讓頁面對使用者操作做出回應

事件監聽器是前端互動的基礎。addEventListener 綁定監聽、removeEventListener 解除綁定，搭配事件代理可以高效管理大量動態元素的事件。

基本用法

綁定、解除、事件物件

// 綁定事件監聽器
function handleClick(event) {
  console.log('Type:', event.type);    // "click"
  console.log('Target:', event.target); // 被點擊的元素
}

btn.addEventListener('click', handleClick);

// 移除監聽器（必須傳相同函式參考）
btn.removeEventListener('click', handleClick);

// 只觸發一次後自動移除
btn.addEventListener('click', handleClick, { once: true });
⚠

用匿名函式當監聽器時，removeEventListener 無效，因為每次都是新函式參考。要移除監聽器，必須先把函式存在變數裡。

延伸追問

面試官可能再追

addEventListener 和 onclick 有什麼差別？

onclick（HTML 屬性或 DOM 屬性）只能綁定一個處理器，後設的會覆蓋前者；addEventListener 可以綁定多個獨立的監聽器，不會互相覆蓋。

passive 選項有什麼用？

{ passive: true } 告知瀏覽器此監聽器不會呼叫 preventDefault()，讓瀏覽器提前開始捲動，改善滾動效能。用在 scroll、touchstart 等事件上效果明顯。

面試這樣答

30 秒版本

「addEventListener(eventType, handler, options) 是綁定事件的標準方式，可以對同一元素綁定多個監聽器；要移除監聽器用 removeEventListener，必須傳入相同的函式參考（所以不能用匿名函式）。常用選項：{ once: true } 只觸發一次後自動移除、{ passive: true } 提升捲動效能。大量元素的事件用事件代理，只在父元素綁定一個監聽器。」
