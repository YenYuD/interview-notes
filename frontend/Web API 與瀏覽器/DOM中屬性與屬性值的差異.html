HTML Attribute vs DOM Property：靜態初始值與動態當前狀態的差異

Attribute 寫在 HTML 標記裡，固定不動；Property 存在 DOM 物件上，隨使用者操作即時變化。這個差異在表單開發與 debug 時尤為關鍵。

核心差異

一句話區分兩者

面向Attribute（屬性）Property（屬性值）
定義位置HTML 標記DOM 物件
狀態靜態（初始值）動態（當前值）
存取方式getAttribute() / setAttribute()直接存取 element.value
使用者操作後不變隨之改變
經典範例

<input> 的 value 最能說明這個差異

// HTML: <input id="name" value="初始值" />

const input = document.getElementById('name');

// 使用者在輸入框輸入「新文字」後：
input.getAttribute('value'); // "初始值" ← Attribute 永遠不變
input.value;               // "新文字" ← Property 反映當前狀態
💡

要取得使用者目前輸入的內容，一定要用 element.value（Property），而不是 getAttribute('value')。

延伸追問

面試官可能再追

什麼情況下 Attribute 和 Property 的值會不同步？

使用者互動後（如修改 input 的值、勾選 checkbox），Property 會更新但 Attribute 不會。若透過 JS 呼叫 setAttribute()，兩者才會同步。

布林 Attribute 如 disabled、checked 有何特殊行為？

HTML 中只要 Attribute 存在就生效（值是 "true" 還是 "false" 都沒差），但 Property 回傳的是布林值 true/false，語義更清晰。

面試這樣答

30 秒版本

「Attribute 是 HTML 標記裡寫的初始值，靜態不變，用 getAttribute() 存取；Property 是 DOM 物件上的屬性，反映元素的當前狀態，會隨使用者操作改變。最常見的例子就是 <input> 的 value：getAttribute('value') 永遠回傳初始值，element.value 才是使用者目前輸入的內容。」
