JAVASCRIPT · 作用域

變數能不能被讀到，取決於它在哪裡被宣告

作用域決定了變數的可見範圍。JavaScript 有全域、函式、區塊三層，理解這三層是掌握閉包、提升、模組封裝的基礎。

三層作用域

全域、函式、區塊

全域作用域：在任何函式或區塊外宣告，整個腳本都可存取。瀏覽器中成為 window 的屬性。
函式作用域：在函式內宣告，只能在函式內存取。var 是函式作用域。
區塊作用域（ES6）：在 {} 區塊內用 let/const 宣告，只在區塊內有效。
var globalVar = '全域';

function myFunction() {
  var functionVar = '函式內';
  if (true) {
    let blockVar = '區塊內';
    console.log(blockVar);   // ✓ 可存取
  }
  // console.log(blockVar); // ✗ ReferenceError
}
// console.log(functionVar); // ✗ ReferenceError
詞法作用域

作用域在定義時決定，不是執行時

JavaScript 採用靜態（詞法）作用域：函式能存取的外層變數，由函式宣告的位置決定，而不是呼叫位置。這是閉包的基礎。

function outer() {
  let x = 10;
  function inner() {
    console.log(x); // 10 — 詞法作用域，可存取外層的 x
  }
  inner();
}
outer();
延伸追問

面試官可能再追

作用域鏈（Scope Chain）是什麼？

當引擎查詢某個變數時，會從目前作用域向外逐層查找，直到全域作用域為止，這條查找路徑就是作用域鏈。找不到就拋出 ReferenceError。

全域變數的問題是什麼？

全域變數會污染命名空間，容易被任何程式碼覆寫，在多個腳本並存時尤其危險。現代開發用模組（ES modules）或 IIFE 封裝，避免洩漏全域。

30 秒版本

「JavaScript 有三種作用域：全域、函式、區塊。var 是函式作用域，let/const 是區塊作用域。JS 採靜態詞法作用域，變數的可見範圍在程式碼撰寫時就固定了，不受呼叫位置影響。查詢變數時引擎沿作用域鏈向外尋找，這也是閉包能捕捉外層變數的原因。」
