迴圈控制的兩個開關：break 終止，continue 跳過

break 讓迴圈提前結束；continue 跳過本次迭代、直接進入下一輪。理解差異，才能正確實作搜尋中斷、條件過濾等常見邏輯。

核心差異

break vs continue

break立即跳出整個迴圈或 switch
continue跳過本次迭代，繼續下一輪
// break — 找到目標就停
for (let i = 0; i < 10; i++) {
  if (i === 5) break;
  console.log(i); // 0 1 2 3 4
}

// continue — 跳過特定值
for (let i = 0; i < 10; i++) {
  if (i === 5) continue;
  console.log(i); // 0 1 2 3 4 6 7 8 9
}
switch 中的 break

防止穿透行為

switch 語句中，若省略 break 會發生穿透（fall-through）：從匹配的 case 繼續執行下一個 case，直到遇到 break 或 switch 結束。

let day = 2;
switch (day) {
  case 1: console.log('Monday'); break;
  case 2: console.log('Tuesday'); break; // 若省略 break，會繼續印 Wednesday
  case 3: console.log('Wednesday'); break;
}
💡

穿透行為偶爾被刻意利用（如多個 case 共用同一段邏輯），但要加上清楚的注解，否則容易被誤判為 bug。

延伸追問

面試官可能再追

巢狀迴圈中，break 只跳出哪一層？

只跳出最近的一層迴圈。若要跳出外層迴圈，可以使用標籤（label）語法：outer: for(...){ inner: for(...){ break outer; } }，但實務上較少見。

forEach 中能用 break 嗎？

不能。forEach 是函式呼叫而非迴圈語法，break/continue 都無法用。想提前中止，改用傳統 for 迴圈，或用 some()/every() 利用回傳值中斷。

面試這樣答

30 秒版本

「break 是完全終止迴圈或 switch，continue 是跳過目前這次迭代繼續下一輪。switch 中每個 case 通常需要 break 防止穿透行為。需要注意的是，forEach 裡無法使用 break，如果需要提前中斷迭代，應改用 for...of 或 some()/every()。」
