定義時叫參數，呼叫時才叫引數

Parameter（參數）是函式定義中的佔位符；Argument（引數）是呼叫函式時實際傳入的值。兩者是同一概念的不同時機，卻常被混淆。

定義釐清

概念對照

Parameter 參數函式定義時的變數名稱
Argument 引數函式呼叫時傳入的實際值
// a, b 是 parameter（參數）
function add(a, b) {
  return a + b;
}

// 2, 3 是 argument（引數）
const result = add(2, 3);
console.log(result); // 5
傳值 vs 傳參考

引數的傳遞方式

原始值（number、string 等）以複製傳遞；物件以參考傳遞，函式內修改物件屬性會影響外部。

function modifyNum(n) { n = 99; } // 原始值：複製，外部不受影響
let x = 1;
modifyNum(x);
console.log(x); // 1 — 不變

function modifyObj(obj) { obj.name = 'Bob'; } // 物件：參考傳遞
let user = { name: 'Alice' };
modifyObj(user);
console.log(user.name); // 'Bob' — 被修改了
延伸追問

面試官可能再追

傳入的引數比參數多或少會怎樣？

多餘引數被忽略（可用 arguments 物件或 rest 參數 ...args 取得）；少傳引數時對應參數值為 undefined，這正是預設參數存在的原因。

arguments 物件和 rest 參數的差異？

arguments 是類陣列物件，存在所有傳統函式中；rest 參數（...args）是真正的陣列，且箭頭函式沒有 arguments 物件。現代 JS 建議用 rest 參數取代 arguments。

面試這樣答

30 秒版本

「Parameter 是定義時的佔位符，Argument 是呼叫時傳入的值，兩者是同一個概念在不同時機的稱呼。傳遞方式上，原始值是複製傳遞（pass by value），物件是傳遞參考（pass by reference），所以函式內修改物件屬性會影響外部，但重新賦值整個物件不會影響外部。」
