宣告前就用變數，有時 undefined，有時直接報錯

提升（Hoisting）是引擎在執行前先「登記」作用域內的宣告。重點是：var 會被初始化成 undefined，let/const 不會——後者在宣告前是「暫時性死區」。

延伸追問

面試官可能再追

函式宣告和函式表達式差在哪？

函式宣告 function foo(){} 連同定義整個提升，宣告前就能呼叫；函式表達式 var foo = function(){} 只提升變數，宣告前是 undefined，呼叫會 TypeError。

「提升」是真的把程式碼搬上去嗎？

不是。引擎在編譯階段先在作用域建立好變數紀錄（var 設 undefined、let/const 標記為不可用），只是行為看起來像宣告被移到頂端。

面試這樣答

30 秒版本

「提升是引擎在執行前先登記作用域內的宣告。var 會初始化成 undefined，所以宣告前讀到 undefined；let / const / class 不初始化，宣告前讀到會 ReferenceError，這段叫暫時性死區。函式宣告連定義一起提升、可提前呼叫，函式表達式則不行。實務上我一律用 let/const 並在頂端宣告來避免這些坑。」
