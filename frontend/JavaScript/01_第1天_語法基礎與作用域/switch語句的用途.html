多條件分支的好讀寫法，但漏寫 break 就會穿透

switch 是多個 if...else if 的替代方案，當同一個值需要對應多種情境時更清晰。理解嚴格比對與穿透（fall-through）是使用關鍵。

語法結構

switch 如何運作

評估表達式：switch 只計算一次表達式的值
嚴格比對：用 === 與每個 case 比較，類型不同不會匹配
執行 + break：找到匹配後執行程式碼，遇到 break 才停下
default：所有 case 都不符合時的備案（可省略）
switch (fruit) {
  case 'apple':
    console.log('Apple is red.');
    break;
  case 'banana':
    console.log('Banana is yellow.');
    break;
  default:
    console.log('Unknown fruit.');
}
穿透行為

break 不能忘

省略 break 時，switch 會繼續執行下一個 case 的程式碼，稱為穿透（fall-through）。有時刻意使用，但更多時候是 bug。

⚠️

switch 使用 === 比對，所以 switch(1) 不會匹配 case '1'（number vs string）。

延伸追問

面試官可能再追

switch 和 if-else 如何選擇？

當比較的是同一個變數對應的多個固定值時，switch 更清晰；如果條件是範圍比較（如 >、<）或不同變數的判斷，用 if-else 更合適。現代 JS 也常用物件字面量或 Map 取代 switch 提升可維護性。

switch 能使用範圍比對嗎？

不直接支援，但可以用 switch(true) 技巧：switch(true){ case score >= 90: ... }，雖然可行，但可讀性較差，大多數情況下 if-else 更好。
