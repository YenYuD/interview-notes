字串轉數字，四種方法各有適用場景

JavaScript 提供 Number()、parseInt()、parseFloat()、一元加號 + 四種轉換方式，差別在於能否處理小數、基底（radix）以及非數字字串的行為。

選用指引

什麼情況用哪個

Number()嚴格轉換，結果必須是純數字字串
parseInt()解析帶有非數字尾綴的字串（如 CSS px 值）
parseFloat()需要保留小數的解析
+str簡短寫法，但可讀性差，不建議在生產代碼用
⚠️

parseInt 不傳第二個 radix 參數時，遇到 '08' 等情況可能有意外行為。建議永遠傳入 10：parseInt(str, 10)。

面試官可能再追

如何偵測轉換失敗（NaN）？

用 Number.isNaN(value)，不要用全域的 isNaN()，因為後者會先強制轉型再判斷，isNaN('abc') 回傳 true 但 Number.isNaN('abc') 回傳 false。

空字串轉數字是什麼？

Number('') 和 +'' 都是 0，這容易造成意外判斷，需留意。
