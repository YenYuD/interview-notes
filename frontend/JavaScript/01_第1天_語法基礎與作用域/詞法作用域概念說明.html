JAVASCRIPT · 作用域

函式記住它在哪裡被定義，不是在哪裡被呼叫

詞法作用域（Lexical Scope）意味著變數的可見範圍在程式碼撰寫時就決定了，而非執行時。這個特性讓閉包（Closure）成為可能：函式帶著它出生時的作用域一起旅行。

核心概念

定義位置決定作用域

function outerFunction() {
  let outerVar = 'I am outside!';

  function innerFunction() {
    // innerFunction 定義在 outerFunction 內部
    // 所以可以存取 outerVar（詞法作用域）
    console.log(outerVar); // 'I am outside!'
  }

  innerFunction();
}
outerFunction();
「詞法」（Lexical）就是指「程式碼文字的位置」。函式在哪裡被寫下來，它的作用域鏈就在那裡被確定，不受後來的呼叫位置影響。
通往閉包

詞法作用域 + 函式回傳 = 閉包

function outerFunction() {
  let outerVar = 'I am outside!';

  return function innerFunction() {
    console.log(outerVar); // 仍然可以存取！
  };
}

const fn = outerFunction(); // outerFunction 已執行完畢
fn(); // 'I am outside!' — 閉包保住了 outerVar
ℹ️

閉包的本質就是函式透過詞法作用域「記住」了它被建立時的外部環境，即使那個外部函式已執行完畢。

延伸追問

面試官可能再追

JavaScript 是靜態作用域還是動態作用域？

靜態（詞法）作用域。動態作用域語言（如早期 Lisp）的作用域由呼叫鏈決定；JS 由定義位置決定。this 的行為有點像動態作用域（受呼叫方式影響），但作用域鏈本身是靜態的。

詞法作用域和閉包的關係？

閉包是詞法作用域的直接結果：函式帶著它定義時的環境（lexical environment）參考走，即使外層函式已返回，內層函式仍能存取那個環境中的變數。

面試這樣答

30 秒版本

「詞法作用域的意思是：函式能存取哪些外部變數，由它定義的位置決定，而不是呼叫的位置。JS 是靜態（詞法）作用域語言，所以巢狀函式可以存取外層宣告的變數。這也是閉包的基礎——函式帶著自己出生時的作用域一起被回傳，外層函式執行完畢後，內層函式仍能存取外層的變數。」
