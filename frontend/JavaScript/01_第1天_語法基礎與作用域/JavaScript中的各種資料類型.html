原始值 vs 參考值：一個複製，一個共享

JavaScript 的類型分兩大類：7 種 Primitive（原始）和Object（參考）。原始值按值複製，物件按參考共享。這個差異決定了賦值、比較、函式傳參的所有行為。

面試官可能再追

原始值和物件的賦值行為差異？

原始值賦值是複製值本身；物件賦值是複製參考位址（reference）。兩個變數指向同一物件時，透過任一變數修改都會影響另一個。

如何正確判斷一個值是陣列？

用 Array.isArray(value)，因為 typeof [] 回傳 'object'，無法區分陣列和普通物件。

30 秒版本

「JS 有 7 種原始類型：number、string、boolean、undefined、null、symbol、bigint，還有 Object 這個參考類型。原始值按值傳遞、複製；物件按參考傳遞、共享記憶體位址。typeof 是常用的類型判斷工具，但有兩個例外需要特別注意：typeof null 是 'object'（歷史 bug），陣列要用 Array.isArray() 而不是 typeof。」
