if-else 的單行版本，但巢狀過深就該收手

三元運算子（ternary operator）是 JavaScript 唯一接受三個運算元的運算子：condition ? expr1 : expr2。簡潔但不能濫用，巢狀超過兩層就是可讀性殺手。

基本語法

三元運算子結構

// 語法：condition ? 為真的值 : 為假的值
let age = 18;
let canVote = age >= 18 ? 'Yes' : 'No';
console.log(canVote); // 'Yes'

// 等同於：
let canVoteIf;
if (age >= 18) { canVoteIf = 'Yes'; }
else { canVoteIf = 'No'; }
適用 vs 不適用

何時用，何時別用

適合簡單的值指派或 JSX 條件渲染
適合兩個明確對立的結果
避免巢狀超過兩層，改用 if-else 或物件映射
避免運算結果有副作用（如 console.log）
⚠️

巢狀三元在視覺上難以追蹤 true/false 分支，應拆成 if-else 或用物件 lookup 取代。

延伸追問

面試官可能再追

三元運算子和 && / || 的短路求值有何不同？

&& 和 || 是基於 truthiness 短路求值，不一定回傳 boolean；三元運算子明確有兩個分支，更適合需要明確 true/false 分支的情境。React JSX 常用 && 做條件渲染（如 isLoggedIn && <Dashboard />），但要注意 0 && ... 會渲染數字 0。

面試這樣答

30 秒版本

「三元運算子是 condition ? true值 : false值，是 if-else 的簡潔寫法。適合單行、簡單的條件賦值，在 React JSX 中也很常見。但如果條件複雜或需要巢狀超過一層，可讀性會急速下降，這時應該改用 if-else 或用物件映射取代，維護性更好。」
