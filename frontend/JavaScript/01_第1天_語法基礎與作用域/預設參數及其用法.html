引數沒傳就用預設值，省掉一堆防禦性檢查

ES6 的預設參數（default parameter）讓你直接在函式簽章宣告回退值，不再需要 if (x === undefined) x = 預設值 的樣板程式碼，也讓函式意圖更清晰。

基本用法

語法與觸發條件

// ES6 預設參數
function greet(name = 'Guest') {
  console.log(`Hello, ${name}!`);
}

greet();          // Hello, Guest! （未傳，用預設值）
greet('Alice');  // Hello, Alice!
greet(undefined); // Hello, Guest! （傳 undefined 也觸發預設值）
greet(null);      // Hello, null!  （null ≠ undefined，不觸發）
⚠️

只有 undefined 才會觸發預設值，傳入 null、0、''（空字串）等 falsy 值不會觸發。

進階用法

預設值可以是運算式

// 後面的預設值可引用前面的參數
function add(a = 0, b = a + 1) {
  return a + b;
}
add();     // 0 + 1 = 1
add(5);    // 5 + 6 = 11
add(5, 10); // 5 + 10 = 15
預設值在呼叫時才被求值，不是在定義時。這表示預設值是動態的，每次呼叫都會重新計算。
延伸追問

面試官可能再追

ES6 之前怎麼做預設參數？

用 || 運算子：name = name || 'Guest'，但這有個問題——0、空字串、false 這類 falsy 值也會被取代成預設值，行為不精確。ES6 預設參數只對 undefined 觸發，更安全。

有預設值的參數要放在哪裡？

應該放在最後面，否則前面有預設值的參數仍然佔位，呼叫者必須明確傳 undefined 才能跳過，使用起來非常不直觀。

面試這樣答

30 秒版本

「預設參數是 ES6 讓函式在引數未傳或為 undefined 時自動使用指定值的語法。比舊的 x = x || 預設值 更安全，因為只有 undefined 才觸發，不會誤傷 0 或空字串。預設值本身也可以是運算式，甚至引用前面的參數。有預設值的參數習慣上要放在參數列最後面。」
