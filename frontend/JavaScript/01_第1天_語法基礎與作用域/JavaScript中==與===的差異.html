0 == '' 是 true，但 0 === '' 是 false

== 比較前會偷偷轉型，常產生反直覺結果；=== 不轉型，型別不同直接 false。結論很簡單：幾乎永遠用 ===。

延伸追問

面試官可能再追

Object.is() 和 === 差在哪？

幾乎一樣，只有兩個邊界不同：Object.is(NaN, NaN) 是 true（=== 是 false），且 Object.is(+0, -0) 是 false（=== 是 true）。

NaN === NaN 是什麼？

是 false——NaN 不等於任何值，包含自己。要判斷用 Number.isNaN()。
