模板字面量的隱藏技：
用函式接管字串的組裝

Tagged templates 在反引號前面加上一個函式名稱，讓你完全控制模板的解析方式。styled-components 的 CSS-in-JS 語法、GraphQL 的 gql``，都是 tagged templates 的實際應用。

運作原理

tag 函式收到什麼？

當你寫 tag\`Hello ${name}!\`，JS 引擎會把模板拆成兩部分傳給函式：

strings字面字串陣列，此例：["Hello ", "!"]
...values插值的求值結果，此例：[name 的值]
function tag(strings, ...values) {
  // strings[0] = "Hello "  values[0] = "World"
  // strings[1] = "!"
  return strings[0] + values[0].toUpperCase() + strings[1];
}

tag`Hello ${'World'}!`; // "Hello WORLD!"
strings.length 永遠比 values.length 多 1。模板開頭若是插值，strings[0] 為空字串；結尾若是插值，最後一個 strings 為空字串。
實務應用

三個最有用的場景

1

HTML 跳脫（防 XSS）

對插入的使用者輸入自動轉義 <、>、&，讓模板安全輸出 HTML。

2

CSS-in-JS（styled-components）

styled.div\`color: ${props => props.primary ? 'blue' : 'gray'}\` — tag 函式解析 CSS 並處理動態值。

3

GraphQL 查詢（gql）

gql\`query { user { id } }\` — tag 函式把字串解析成 AST 物件，不是傳回字串。

// HTML 跳脫 tag 函式範例
function safeHtml(strings, ...values) {
  return strings.reduce((acc, str, i) => {
    const val = values[i - 1];
    const escaped = val
      ? String(val)
          .replace(/&/g, '&')
          .replace(/'<')
          .replace(/>/g, '>')
      : '';
    return acc + escaped + str;
  });
}
const input = '<script>alert(1)</script>';
safeHtml`<p>${input}</p>`;
// "<p>&lt;script&gt;alert(1)...</p>"
延伸追問

面試官可能再追

tag 函式一定要回傳字串嗎？

不必要。tag 函式可以回傳任意值，包含物件、陣列、DOM 元素。gql tag 就是回傳一個 AST 物件，html tag（lit-html）回傳的是可被框架直接渲染的模板物件。

strings.raw 是什麼？

strings.raw 是 strings 陣列的一個特殊屬性，包含各個字串片段的原始內容（不處理跳脫序列，如 \n 保持為兩個字元 \ + n）。String.raw 本身就是一個內建 tag 函式，輸出不處理跳脫的原始字串，常用於寫正則表達式或 Windows 路徑。
