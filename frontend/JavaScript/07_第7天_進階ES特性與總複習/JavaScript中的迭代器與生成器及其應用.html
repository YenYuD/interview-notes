JAVASCRIPT / ES6+

暫停、繼續、按需產值——
生成器改變非同步的寫法

迭代器定義「逐一取值」的協定，生成器（function* + yield）讓你用同步風格寫出可暫停的函式。從惰性求值、無限序列到分批非同步資料流，都是它們的舞台。

迭代器協定

實作 next() 就能被 for...of 消費

只要一個物件有 [Symbol.iterator]() 方法回傳含 next() 的物件，它就是可迭代（iterable）的。

class Range {
  constructor(from, to) { this.from = from; this.to = to; }
  [Symbol.iterator]() {
    let cur = this.from, end = this.to;
    return {
      next() {
        return cur <= end
          ? { value: cur++, done: false }
          : { value: undefined, done: true };
      }
    };
  }
}
[...new Range(1, 3)]; // [1, 2, 3]
i

內建支援迭代器的有：Array、String、Map、Set、NodeList，以及函式的 arguments。它們都能直接 for...of 或展開（...）。

生成器

用 function* 和 yield 實作可暫停函式

上面的 Range 用生成器改寫，程式碼更簡潔：

class Range {
  constructor(from, to) { this.from = from; this.to = to; }
  *[Symbol.iterator]() {
    for (let i = this.from; i <= this.to; i++) yield i;
  }
}
// 無限序列也沒問題，消費端控制停止
function* naturals() { let n = 0; while(true) yield n++; }
const gen = naturals();
gen.next().value; // 0
gen.next().value; // 1
惰性求值只在 next() 時才計算，節省記憶體
無限序列while(true) + yield，不會佔滿記憶體
可雙向傳值next(val) 可把值傳回生成器內部
非同步生成器

分批拉取 API 資料的優雅寫法

async function* fetchPages(url, pages = 3) {
  for (let p = 1; p <= pages; p++) {
    const res = await fetch(`${url}?_page=${p}`);
    yield await res.json();  // 每次 await 一頁
  }
}

for await (const batch of fetchPages('/api/items')) {
  processBatch(batch);  // 拿到一頁就處理，不用等全部
}
✓

Redux-Saga 的 put/take/call effect 底層正是生成器；它讓非同步副作用的測試變得極容易（只需 call next() 驗證每一步 effect）。

延伸追問

面試官可能再追

迭代器和可迭代物件（iterable）有什麼差別？

迭代器是有 next() 方法的物件；可迭代物件是有 [Symbol.iterator]() 方法並回傳迭代器的物件。生成器函式執行後回傳的物件兩者兼具：它既有 next()，也有 [Symbol.iterator] 回傳自身，所以可以直接丟進 for...of。

生成器可以提前終止嗎？

可以。呼叫 gen.return(value) 會終止生成器並觸發 finally 清理邏輯；呼叫 gen.throw(error) 會在生成器當前暫停的位置拋出例外。for...of 用 break 跳出時，引擎會自動呼叫 .return()。

async/await 和生成器有什麼關係？

歷史上，async/await 在語言層面是以生成器為概念基礎設計的（早期用 co 函式庫搭配生成器模擬）。現代引擎 async/await 是原生實作，效能更好；但生成器在需要「外部控制」執行步驟的場景（如 Redux-Saga）仍不可取代。

面試這樣答

30 秒版本

「迭代器是實作了 next() 方法、回傳 { value, done } 的物件；任何帶有 [Symbol.iterator] 的物件都可以用 for...of 消費。生成器（function* + yield）是建立迭代器最簡潔的方式，特點是執行可以暫停並在呼叫 next() 時繼續，非常適合惰性求值、無限序列與分批非同步資料流。async function* 搭配 for await...of 是處理分頁 API 或串流資料的優雅方案。」
