函式式程式設計・部分套用

先填一部分，剩下的以後再補：Partial Application

部分應用是預先固定函式的部分參數，回傳一個「還差幾個參數」的新函式。最直接的實現是 Function.prototype.bind，無需自己手寫。

核心概念

bind 就是最簡單的部分套用

function add(a, b) { return a + b; }

// 用 bind 固定第一個參數
const add5 = add.bind(null, 5);
add5(10); // 15
add5(20); // 25

也可以自己實作一個更靈活的 partial：

function partial(fn, ...fixedArgs) {
  return function(...remainingArgs) {
    return fn(...fixedArgs, ...remainingArgs);
  };
}

const greet = (greeting, name) => `${greeting}, ${name}!`;
const sayHello = partial(greet, 'Hello');
sayHello('Alice'); // 'Hello, Alice!'
sayHello('Bob');   // 'Hello, Bob!'
優點

為什麼要用部分套用？

好處說明
減少重複相同的前段參數只填一次
提升語意add5 比 add.bind(null, 5) 在呼叫點更易讀
延遲執行先配置好函式，之後在正確時機傳入剩餘參數
✅

bind 的部分套用只能從左側固定參數。若需固定中間或右側的參數，使用自定義 partial 函式，或考慮 Lodash 的 _.partial / _.partialRight。

面試官可能再追

部分套用和柯里化的區別？

柯里化每次嚴格只接受一個參數；部分套用可以一次固定多個參數。柯里化後的函式天然支援部分套用，但部分套用不一定是柯里化。

實際使用 bind 做部分套用時，thisArg 傳 null 的意義？

當你只是借用 bind 做部分套用、不關心函式內的 this 時，傳 null 表示「不指定 this」。若在嚴格模式下，this 會是 null；非嚴格模式會退回全域物件。
