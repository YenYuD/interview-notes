接受函式、也能回傳函式：Higher-Order Function

高階函式（Higher-Order Function）是「把函式當一等公民」的核心：它可以接收函式作為參數，或回傳一個新函式。map、filter、reduce 就是最日常的例子。

定義

符合其中一條就算

接受函式作為參數 — 例如 arr.map(fn)，把轉換邏輯交給外部決定
回傳函式作為結果 — 例如 multiplier(2) 回傳「乘以 2」的函式，延遲執行
函式作為參數（map） 
['a','b','c'].map(x => x.toUpperCase());
// ['A', 'B', 'C']
回傳函式（工廠模式） 
function multiplier(n) {
  return (x) => x * n;
}
const double = multiplier(2);
double(5); // 10
實務延伸

高階函式讓程式碼更宣告式

命令式寫法需要手動管理迴圈；高階函式讓你只描述「做什麼」，不管「怎麼做」：

// 命令式：逐行告訴電腦怎麼做
const result = [];
for (let i = 0; i < names.length; i++) {
  result.push(names[i].toUpperCase());
}

// 宣告式：告訴電腦你要什麼
const result = names.map(n => n.toUpperCase());
ℹ️

常見的高階函式：Array.map / filter / reduce / forEach，以及 Function.prototype.bind（回傳新函式）。

延伸追問

面試官可能再追

高階函式和閉包有什麼關係？

高階函式回傳的函式通常就是閉包——它「記住」了外層函式的變數。例如 multiplier(2) 回傳的函式閉包住了 n=2。

reduce 是高階函式嗎？請說明。

是。reduce(fn, initialValue) 接受一個 reducer 函式作為參數，符合「接受函式為參數」的定義。
