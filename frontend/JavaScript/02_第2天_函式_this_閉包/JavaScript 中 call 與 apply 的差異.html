函式・this 控制

同樣借 this，差在參數怎麼傳：call vs apply

call 和 apply 都能讓你指定函式執行時的 this，差別只有一個：call 逐一列舉參數，apply 傳入陣列。ES6 展開運算子出現後，apply 的使用場景大幅縮減。

核心差異

同樣的 this，不同的參數格式

call(thisArg, a, b, c)apply(thisArg, [a, b, c])
參數形式逐一列舉（comma-separated）陣列一次傳入
執行時機立即執行立即執行
記憶法Call → CommasApply → Array
function add(a, b) { return a + b; }

add.call(null, 1, 2);      // 3 — 參數逐一列舉
add.apply(null, [1, 2]);   // 3 — 參數包成陣列

// ES6 之後，apply 可用展開運算子取代
add.call(null, ...[1, 2]); // 3
使用情境

什麼時候真的需要它們？

借用方法（Method Borrowing） 
function greet() {
  console.log(`Hi, I'm ${this.name}`);
}
greet.call({ name: 'Alice' }); // Hi, I'm Alice
apply 合併陣列（老寫法） 
const a = [1, 2, 3], b = [4, 5, 6];
// 等同 a.push(...b)
Array.prototype.push.apply(a, b);
✅

現代 JavaScript 中，apply 最常見的功能（把陣列展開為參數）幾乎都被展開運算子 ... 取代，call 反而更常見。

延伸追問

面試官可能再追

call / apply 和 bind 有什麼不同？

call/apply 立即執行並返回結果；bind 回傳一個綁定了 this 的新函式，不立即執行，適合做事件處理器或回呼。

箭頭函式能用 call / apply 改變 this 嗎？

不能。箭頭函式的 this 在定義時就詞法綁定，call/apply/bind 都無法覆蓋它。

面試這樣答

30 秒版本

「call 和 apply 都能在呼叫函式時明確指定 this 的值，兩者立即執行、行為相同，唯一差別是參數格式：call 逐一列舉，apply 傳陣列——口訣是 C 代表 Commas，A 代表 Array。ES6 後，apply 的陣列場景幾乎被展開運算子取代，但借用方法時兩者都還很常見。與 bind 的差別是 bind 不立即執行，返回新函式。」
