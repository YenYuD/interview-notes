函式・匿名函式

沒有名字，但無處不在：匿名函式的三大舞台

匿名函式（anonymous function）是沒有名稱的函式，通常當作參數傳入或立即執行。它是回呼、IIFE、陣列方法的主角，也是現代箭頭函式語法的基礎。

三種典型用法

什麼場合最適合匿名函式？

回呼函式（Callback） — 傳入其他函式作為行為參數 
setTimeout(() => console.log('Hello!'), 1000);
IIFE（立即執行函式表達式） — 封裝作用域，避免污染全域 
(function() {
  var x = 10; // 外部看不到 x
})();
陣列方法 / 高階函式 — 一次性轉換邏輯 
[1,2,3].map(n => n * 2); // [2,4,6]

⚠️

匿名函式在 Stack Trace 中顯示為 anonymous，除錯時難以定位問題。若函式邏輯複雜或會被多次引用，建議改用具名函式表達式，例如 const fn = function myFn() {...}。

面試官可能再追

匿名函式和箭頭函式是同一件事嗎？

不完全是。箭頭函式通常沒有名稱（匿名），但「匿名」指無名稱，「箭頭」指語法形式。箭頭函式還多了「無自己的 this」的特性，這是普通匿名函式沒有的。

IIFE 在 ES6 模組流行後還有必要嗎？

ES6 模組（import/export）每個檔案自成作用域，舊有「防污染全域」的需求幾乎消失。IIFE 現在主要用於需要立即初始化但不想建立命名函式的一次性邏輯。

面試這樣答

30 秒版本

「匿名函式是沒有識別符的函式，最常見於三個場景：作為回呼（如 setTimeout）、IIFE（封裝一次性作用域）、以及陣列高階方法（map/filter/reduce）。箭頭函式是匿名函式的現代語法，但多了詞法 this 繼承的特性。需要注意的是，匿名函式在 Stack Trace 中難以追蹤，複雜邏輯建議改用具名函式表達式。」
