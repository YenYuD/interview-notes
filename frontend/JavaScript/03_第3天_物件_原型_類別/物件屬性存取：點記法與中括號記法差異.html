點記法能做的 90%，中括號記法全都能

兩種存取物件屬性的語法各有適用場景：點記法簡潔直觀；中括號記法可用變數動態決定屬性名，也能處理含空格或特殊字元的 key。

語法對照

什麼情況只能用中括號？

情境點記法中括號記法
一般識別字屬性✓ obj.name✓ obj['name']
含空白 / 特殊字元的 key✗✓ obj['favorite color']
以數字開頭的 key✗✓ obj['1st']
動態 key（變數）✗✓ obj[someVar]
保留字為 key（ES5 以前）✗（現代 ES 已允許）✓ 永遠安全
動態屬性存取

中括號記法的核心優勢

const user = { name: 'Alice', age: 28, role: 'admin' };
const key = 'role'; // 可來自使用者輸入、函式參數…

// 點記法無法動態
console.log(user.key);   // undefined（找名為 "key" 的屬性）

// 中括號記法可動態
console.log(user[key]);  // 'admin' ✓

// 常見應用：動態 form 欄位更新
function updateField(obj, field, value) {
  obj[field] = value;
}

面試官可能再追

中括號記法裡可以放運算式嗎？

可以，任何有效的 JS 運算式都行，如 obj[i + 1]、obj['pre' + 'fix']、obj[Symbol.iterator]。這讓中括號記法非常靈活。

Computed property name（計算屬性名）是什麼？

ES2015 引入了在物件字面量裡直接用中括號計算 key 的語法：const key = 'name'; const obj = { [key]: 'Alice' }，等同 { name: 'Alice' }。

面試這樣答

30 秒版本

「兩者都能存取物件屬性。點記法更簡潔，日常優先使用；中括號記法有三種點記法辦不到的場景：動態 key（變數）、含空格或特殊字元的 key、以數字開頭的 key。一旦屬性名是在執行期決定的，就必須用中括號。」
