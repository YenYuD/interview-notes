只關「進門」：Object.preventExtensions()

Object.preventExtensions() 是三種物件鎖定方法中限制最少的一種：只阻止新增屬性，現有屬性的修改與刪除仍然允許。

行為說明

防擴展 vs 可修改 vs 可刪除

const obj = { name: 'John' };
Object.preventExtensions(obj);

obj.age = 30;       // ✗ 無法新增新屬性
console.log(obj.age); // undefined

obj.name = 'Jane';  // ✓ 可修改現有屬性
delete obj.name;    // ✓ 可刪除現有屬性
console.log(obj);   // {}
Object.isExtensible(obj) 回傳 false 表示已防擴展。

延伸追問

面試官可能再追

preventExtensions 可以撤銷嗎？

不行。一旦呼叫 Object.preventExtensions()，物件永遠不可擴展，無法逆轉。這和 configurable: false 一樣是單向門。

實際上什麼時候會用 preventExtensions？

比較罕見，通常用在需要「固定物件結構但允許改值」的情境，例如確保 API 回傳物件的 schema 不被呼叫端意外擴充，但允許更新現有欄位。

面試這樣答

30 秒版本

「Object.preventExtensions() 是三種物件鎖定中限制最少的，只防止新增屬性，現有屬性仍可修改或刪除。比較常用的是 seal（防新增 / 刪除、可改值）和 freeze（完全唯讀）。三者都是單向操作，無法撤銷。」
