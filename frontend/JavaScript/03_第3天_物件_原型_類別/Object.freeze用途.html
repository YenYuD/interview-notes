凍住它：Object.freeze() 讓物件無法再變動

Object.freeze() 讓物件進入完全唯讀狀態：屬性值不能改、不能新增、不能刪除。是實現不可變物件最直接的原生方法——但只凍表層。

效果一覽

凍結後做什麼都沒用

const obj = { name: 'John', age: 30 };
Object.freeze(obj);

obj.name = 'Doe';     // ✗ 靜默失敗（strict mode 拋 TypeError）
obj.city = 'Taipei'; // ✗ 無法新增
delete obj.age;      // ✗ 無法刪除

console.log(obj); // { name: 'John', age: 30 }（原封不動）
限制：淺層凍結

巢狀物件仍然可變

const config = Object.freeze({
  db: { host: 'localhost', port: 5432 }
});

config.db.port = 9999; // ✓ 成功！freeze 沒有深入 db 物件
console.log(config.db.port); // 9999
⚠️

freeze 只凍第一層。深層不可變需要遞迴呼叫 freeze，或使用 Immer、Immutable.js。

延伸追問

面試官可能再追

freeze、seal、preventExtensions 三者的差異？

三者的限制程度遞減：freeze（不可改值 + 不可新增 / 刪除）＞ seal（可改值 + 不可新增 / 刪除）＞ preventExtensions（可改值、可刪除 + 僅不可新增）。

如何確認物件是否被凍結？

用 Object.isFrozen(obj)，回傳布林值。類似的有 Object.isSealed()、Object.isExtensible()。
