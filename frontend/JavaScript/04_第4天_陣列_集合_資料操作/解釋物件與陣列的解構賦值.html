JAVASCRIPT · 解構

不用一個個取值，解構賦值一次搞定

解構賦值讓你用模式匹配的方式，把陣列的值或物件的屬性「拆出來」直接賦給變數。配合重新命名、預設值、巢狀解構，能讓函式簽名和賦值邏輯清晰很多。

陣列解構

依位置取值，可以跳過、可以設預設值

const [a, b, c] = [1, 2, 3];
console.log(a, b, c); // 1 2 3

// 跳過第二個元素
const [first, , third] = [10, 20, 30];
console.log(first, third); // 10 30

// 預設值（元素不足時）
const [x, y = 99] = [1];
console.log(x, y); // 1 99

// 交換變數（最優雅的用法）
let p = 1, q = 2;
[p, q] = [q, p]; // p=2, q=1
物件解構

依鍵名取值，可以重新命名

const { name, age } = { name: 'Alice', age: 25 };

// 重新命名：name → personName
const { name: personName, age: personAge = 18 } = { name: 'Bob' };

// 巢狀解構
const { address: { city, zip } } = {
  address: { city: 'Taipei', zip: '100' }
};
✅

函式參數解構非常實用：function greet({ name, age = 0 }) {...}——呼叫方傳物件，函式內直接用具名變數，省去 opts.name 這類重複前綴。

延伸追問

面試官可能再追

解構可以搭配剩餘語法嗎？

可以。陣列：const [first, ...rest] = [1,2,3,4]，rest 是 [2,3,4]；物件：const { a, ...others } = obj，others 是除了 a 以外的屬性。

解構的預設值何時生效？

只有在解構到的值是 undefined 時，才會用預設值。null 不會觸發預設值，null 本身就是值。

面試這樣答

30 秒版本

「解構賦值是 ES6 的語法糖，讓你用模式匹配一次拆出多個值。陣列解構依位置、物件解構依鍵名；兩者都支援預設值和剩餘語法。最實用的場景是函式參數解構，讓 API 設計更清晰，以及 React Hooks 的 const [state, setState] = useState() 這種模式。」
