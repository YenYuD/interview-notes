JAVASCRIPT · 展開運算子

三個點，把可迭代物件攤開的魔法

展開運算子（Spread operator）用 ... 把陣列、字串、Set 等可迭代物件的元素「攤開」到新的陣列或函式呼叫中。複製、合併、傳參——三種最常見的應用場景。

四種用法

陣列、物件、字串、函式參數

// 1. 複製陣列（淺層）
const copy = [...[1, 2, 3]];          // [1, 2, 3]

// 2. 合併陣列
const merged = [...[1,2], ...[3,4]];  // [1, 2, 3, 4]

// 3. 物件展開（淺層複製／合併）
const newObj = { ...obj1, ...obj2 };

// 4. 函式呼叫傳陣列
Math.max(...[3, 1, 4, 1, 5]);         // 5（取代 apply）

// 5. 字串拆成字元陣列
[...'hello'];                         // ['h','e','l','l','o']
限制

不是所有東西都能展開

可以展開 陣列、字串、Set、Map、Generator
不能展開進陣列 普通物件（非 iterable） 
// 物件不能展開進陣列
[...{ a: 1 }]; // ❌ TypeError: not iterable

// 但陣列可以展開進物件（取 index 為鍵）
{ ...[1, 2, 3] }; // ✅ { 0: 1, 1: 2, 2: 3 }
⚠️

展開運算子是淺層複製——巢狀物件或陣列只複製參考，不複製內容。需要深拷貝時改用 structuredClone()。

延伸追問

面試官可能再追

展開運算子和 Object.assign() 有什麼差異？

兩者都是淺層複製。差別在：Object.assign() 會觸發目標物件的 setter；展開則不會，直接定義屬性。另外 Object.assign() 回傳目標物件（有副作用），展開則建立全新物件。

展開進陣列和 concat() 的差異？

功能幾乎相同，但展開語法更直觀且能在任意位置插入：[...a, 0, ...b]。concat 在需要鏈式操作時更適合。

面試這樣答

30 秒版本

「展開運算子（...）把可迭代物件展開成個別元素。最常用在三個地方：複製陣列或物件（淺層）、合併多個陣列或物件、把陣列當函式參數傳入。要注意它是淺層複製，巢狀物件共用同一個參考；需要深拷貝時要另外處理。」
