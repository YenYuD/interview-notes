JAVASCRIPT · 陣列

同樣是跑陣列，選對方法才是主角

JavaScript 的陣列迭代不只一條路：for 迴圈給你完整控制，forEach / map / filter / reduce 讓意圖一目了然，for...of 兼顧彈性與可讀性。

方法速查

六種主流迭代方式一覽

方法回傳值可中斷？最適情境
for—✅ break完全自訂控制、需要跳索引
for...of—✅ break可迭代物件，語法簡潔
forEachundefined❌純副作用操作
map新陣列❌轉換每個元素
filter新陣列❌篩選符合條件的元素
reduce單一值❌累積成一個結果
核心範例

map → filter → reduce 的鏈式思維

// 原始資料
const nums = [1, 2, 3, 4, 5];

// map：每個元素乘 2
nums.map(n => n * 2);       // [2, 4, 6, 8, 10]

// filter：只留偶數
nums.filter(n => n % 2 === 0); // [2, 4]

// reduce：加總
nums.reduce((acc, n) => acc + n, 0); // 15
✅

map / filter / reduce 都不修改原陣列，符合函式式編程的不可變原則。需要中途跳出迴圈時，改用 for...of + break。

延伸追問

面試官可能再追

forEach 和 map 最大的差別？

forEach 回傳 undefined，純粹執行副作用；map 回傳新陣列，不改動原始資料。如果你不需要新陣列，用 forEach 語意更清晰。

reduce 怎麼用來「把陣列轉物件」？

arr.reduce((acc, item) => ({ ...acc, [item.id]: item }), {})——初始值給空物件，每輪把元素合併進去，是常見的 normalize 技巧。

哪些方法可以提早終止？

forEach、map、filter、reduce 都無法用 break 中斷。需要提早終止時，用 for / for...of + break，或用 Array.prototype.some（找到就停）。
