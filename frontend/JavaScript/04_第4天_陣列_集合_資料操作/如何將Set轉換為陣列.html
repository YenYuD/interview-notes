Set 去重後，一行轉回陣列

Set 是集合，陣列才能用 map/filter/sort。轉換方式只有兩種：展開運算子 [...set] 和 Array.from(set)，選哪個都對，差別在語境偏好。

兩種寫法

對比展開運算子與 Array.from()

const s = new Set([1, 2, 3, 2, 1]);

// 方式 1：展開運算子（更簡潔）
const arr1 = [...s];         // [1, 2, 3]

// 方式 2：Array.from()（語意更明確）
const arr2 = Array.from(s);  // [1, 2, 3]

// 最常見的去重慣用法
const unique = [...new Set(someArray)];
✅

Array.from() 還支援第二個 mapFn 參數：Array.from(set, x => x * 2)，可以在轉換的同時做映射，比展開後再 map 少一次迭代。

實用場景

去重的完整流程

原始陣列（含重複） [1, 2, 2, 3, 3, 3]
傳入 Set 自動去重 new Set([1, 2, 2, 3, 3, 3]) → Set {1, 2, 3}
轉回陣列繼續操作 [...new Set(...)] → [1, 2, 3]
延伸追問

面試官可能再追

Set 轉陣列後，順序保證嗎？

保證。Set 保留插入順序，轉換成陣列後元素順序和插入順序一致。

可以從陣列直接轉回 Set 再轉回陣列嗎？效能如何？

可以，但對大型陣列會建立兩個中間資料結構。一般業務場景無需擔心效能，資料量極大時可考慮用 filter + indexOf 或 reduce 手動去重。
