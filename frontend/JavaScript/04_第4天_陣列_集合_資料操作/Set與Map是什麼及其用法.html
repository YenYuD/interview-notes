陣列去重用 Set，鍵值對升級用 Map

Set 是不重複值的集合，Map 是鍵可以是任意類型的鍵值對。兩者都是 ES6 引入的正規資料結構，比土炮方案更簡潔、效能更好。

Set 核心

唯一性集合 — 重複值自動忽略

const s = new Set([1, 2, 2, 3]);
console.log(s.size);   // 3（重複的 2 只保留一個）

s.add(4);            // 新增
s.has(2);            // true
s.delete(1);         // 刪除

// 快速去除陣列重複值
const unique = [...new Set([1,1,2,3,3])];
Map 核心

任意類型為鍵的鍵值對

const m = new Map();
m.set('name', 'Alice');
m.set(42, 'number key');  // 數字當鍵
m.set({id:1}, 'obj key');   // 物件當鍵

m.get('name');   // 'Alice'
m.has(42);       // true
m.size;           // 3

// 遍歷
for (const [k, v] of m) console.log(k, v);
✅

Map 保留插入順序，size 屬性直接告訴你元素數量，遍歷也比物件更直觀。

延伸追問

面試官可能再追

Set 判斷相等的機制是什麼？

Set 使用參考相等（SameValueZero），與 === 幾乎相同（差別只在 NaN：Set 把兩個 NaN 視為相等）。同樣內容的兩個物件字面量是不同參考，Set 會各自保留。

什麼時候用 Map 而非普通物件？

需要非字串鍵、需要保證插入順序、頻繁增刪鍵時用 Map；簡單的字串鍵靜態設定、需要 JSON 序列化時用普通物件。

面試這樣答

30 秒版本

「Set 是只存唯一值的集合，最常用來快速去除陣列重複項，用 [...new Set(arr)] 一行搞定。Map 是鍵可以是任意類型的鍵值對，比普通物件多了非字串鍵、保留插入順序、size 屬性等能力，適合頻繁增刪的大型資料集。」
