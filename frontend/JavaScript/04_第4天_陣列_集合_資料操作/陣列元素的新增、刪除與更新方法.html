splice 解剖

splice(start, deleteCount, ...items)

let arr = [1, 2, 3, 4];

// 在 index 1 刪 2 個，插入 'a', 'b'
arr.splice(1, 2, 'a', 'b');
// arr → [1, 'a', 'b', 4]，回傳 [2, 3]

// 只插入，不刪除
arr.splice(2, 0, 'x');
// arr → [1, 'a', 'x', 'b', 4]
⚠️

splice 會直接修改原陣列。如果需要不可變操作，改用 toSpliced()（ES2023）或展開運算子組合新陣列。

延伸追問

面試官可能再追

push / unshift 哪個效能較好？

push（尾端）通常比 unshift（開頭）快，因為 unshift 要把所有現有元素往後移一位，時間複雜度是 O(n)；push 是 O(1)（均攤）。

刪掉一個元素還有哪些方式？

除 splice，還可以用 filter 建立不含目標元素的新陣列（不可變方式）。delete arr[i] 雖然可以，但只把值變成 undefined，長度不變，通常不建議。
