同樣是 ...，展開和剩餘是兩個反向操作

展開（Spread）把一個陣列／物件拆散成獨立元素；剩餘（Rest）把多個獨立元素收集成一個陣列。同樣三個點，看位置就知道是哪一種。

核心區別

展開：一變多；剩餘：多變一

展開 Spread 出現在「值」的位置，把集合拆開
剩餘 Rest 出現在「參數／解構」的位置，把剩下的收集起來 
// 展開：把陣列拆開傳入函式
const nums = [1, 2, 3];
console.log(Math.max(...nums)); // 3

// 剩餘：把「其餘引數」收進陣列
function sum(...numbers) {
  return numbers.reduce((acc, n) => acc + n, 0);
}
console.log(sum(1, 2, 3, 4)); // 10
解構中的剩餘

收集「剩下的部分」

// 陣列解構的剩餘
const [first, second, ...rest] = [1, 2, 3, 4, 5];
// first=1, second=2, rest=[3,4,5]

// 物件解構的剩餘
const { a, b, ...others } = { a: 1, b: 2, c: 3, d: 4 };
// a=1, b=2, others={ c:3, d:4 }
⚠️

剩餘參數必須放在最後：function fn(a, ...rest, b) 是語法錯誤。函式只能有一個剩餘參數。

剩餘語法比 arguments 物件好用：arguments 是類陣列、不能在箭頭函式裡用；剩餘語法直接是真正的陣列，支援所有陣列方法。
延伸追問

面試官可能再追

剩餘語法和 arguments 的差別？

arguments 是類陣列物件（沒有 map/filter 等方法）、包含所有引數、在箭頭函式裡不可用；剩餘語法是真正的 Array、只收集「其餘」引數（前面已命名的不包含）、可在任何函式使用。

同樣是 ...，怎麼判斷是展開還是剩餘？

看出現的語境：在函式宣告的參數列表或解構賦值的左側是剩餘；在函式呼叫的引數或陣列 / 物件字面量裡是展開。

面試這樣答

30 秒版本

「展開和剩餘語法符號相同，但方向相反。展開出現在值的位置，把集合拆開；剩餘出現在參數或解構的左側，把多個元素收集成陣列。剩餘語法比 arguments 更好用，因為它是真正的陣列，也支援箭頭函式。」
