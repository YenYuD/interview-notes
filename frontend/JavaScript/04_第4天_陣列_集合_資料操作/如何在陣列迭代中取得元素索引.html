跑陣列時，怎麼同時拿到 index？

不同迭代方式取得索引的語法不一樣。forEach 的回呼第二個參數就是 index；for...of 則要搭配 .entries()；傳統 for 迴圈本身就有計數器。

三種姿勢

取得索引的寫法對比

const arr = ['a', 'b', 'c'];

// 1. forEach — 第二個參數是 index
arr.forEach((el, i) => console.log(i, el));

// 2. for...of + entries() — 解構出 [index, element]
for (const [i, el] of arr.entries()) {
  console.log(i, el);
}

// 3. 傳統 for — 計數器 i 就是索引
for (let i = 0; i < arr.length; i++) {
  console.log(i, arr[i]);
}
選擇準則

什麼時候用哪一種？

forEach 純副作用、不需中斷
for...of + entries 需要中斷（break）且語法要優雅
傳統 for 需要精細控制步長或雙向走訪
✅

map 的回呼同樣有 (element, index, array) 三個參數，但如果你只需要 index 而不需要回傳新陣列，不要用 map——語意不清且浪費效能。

延伸追問

面試官可能再追

entries() 回傳什麼？

Array.prototype.entries() 回傳一個迭代器（Iterator），每次迭代吐出 [index, value] 的配對，可以用 for...of 或展開成陣列。

forEach 可以取到陣列本身嗎？

可以，回呼有第三個參數 array，即原始陣列本身。但直接使用外層變數更清晰。

面試這樣答

30 秒版本

「在陣列迭代中取得 index，最常用的是 forEach 的第二個回呼參數；如果需要中途 break，改用 for...of 搭配 arr.entries() 解構；傳統 for 迴圈的計數器本身就是 index，適合需要精細控制的情況。」
